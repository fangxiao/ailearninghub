任务分解

之前我们说了工具系统。Agent能调用工具了，下一步是让它能处理复杂任务。

复杂任务不能一步完成，需要分解成多个子任务。这一篇，我们来说说任务分解。

💡 核心观点：复杂任务 = 多个简单任务的组合。任务分解让Agent能够处理超出单次调用能力范围的工作。

1为什么要任务分解

想象用户说："帮我写一篇关于AI的文章，包括标题、正文，还要配上封面图。"

这个任务至少包含三个子任务：

  1. 写标题
  2. 写正文
  3. 生成封面图

如果Agent不分解任务，它可能会：

  • 只写了标题就结束了
  • 标题和正文混在一起，结构混乱
  • 忘记配图

2自动任务分解

pythonclass TaskDecomposer:
    def decompose(self, task):
        prompt = f"""将以下任务分解成子任务：

任务：{task}

请将任务分解成独立的子任务，每个子任务应该：
1. 可以独立执行
2. 有明确的完成标准
3. 不依赖其他子任务的结果（如果依赖请标注）

以JSON数组格式返回：
[{{"id": 1, "task": "子任务描述", "depends_on": []}}]"""

        response = openai.ChatCompletion.create(
            model="gpt-4",
            messages=[{"role": "user", "content": prompt}]
        )

        import json
        return json.loads(response.choices[0].message["content"])

3依赖分析与并行规划

分解后的子任务，有些可以并行执行，有些必须按顺序执行。

pythonclass TaskScheduler:
    def create_execution_plan(self, tasks):
        # 构建依赖图
        graph = {t["id"]: t.get("depends_on", []) for t in tasks}

        # 找出可以并行的任务
        plan = []
        completed = set()

        while len(completed) < len(tasks):
            # 找出所有依赖都已完成的任务
            ready = []
            for task in tasks:
                tid = task["id"]
                if tid in completed:
                    continue
                if all(dep in completed for dep in graph[tid]):
                    ready.append(task)

            if not ready:
                break  # 环形依赖

            plan.append(ready)
            for t in ready:
                completed.add(t["id"])

        return plan  # [[task1, task2], [task3]] 表示可并行，执行顺序

💡 任务分解的好处：1) 处理复杂任务 2) 任务可并行执行提高效率 3) 便于追踪进度和错误定位

执行引擎

任务分解完了，接下来是执行。执行引擎负责按照计划执行每个子任务。

💡 核心观点：执行引擎就是任务的"调度中心"，管理任务的执行顺序、状态和结果。

1状态机设计

Figure: Task State Machine - Pending -> Running -> Completed/Failed

每个任务都有生命周期：pending → running → completed/failed

pythonclass Task:
    def __init__(self, task_id, description):
        self.task_id = task_id
        self.description = description
        self.status = "pending"  # pending, running, completed, failed
        self.result = None
        self.error = None

2任务队列

pythonclass ExecutionEngine:
    def __init__(self, agent):
        self.agent = agent
        self.tasks = {}
        self.results = {}

    def execute_plan(self, plan):
        for batch in plan:
            # 同一批的任务可以并行执行
            batch_results = []
            for task_spec in batch:
                result = self.execute_task(task_spec)
                batch_results.append(result)

            for result in batch_results:
                self.results[result["task_id"]] = result

        return self.results

    def execute_task(self, task_spec):
        task_id = task_spec["id"]
        task_desc = task_spec["task"]

        try:
            result = self.agent.run(task_desc)
            return {
                "task_id": task_id,
                "status": "completed",
                "result": result
            }
        except Exception as e:
            return {
                "task_id": task_id,
                "status": "failed",
                "error": str(e)
            }

3进度跟踪

pythonclass ProgressTracker:
    def get_progress(self, results):
        total = len(results)
        completed = sum(1 for r in results.values() if r.get("status") == "completed")
        failed = sum(1 for r in results.values() if r.get("status") == "failed")

        return {
            "total": total,
            "completed": completed,
            "failed": failed,
            "percentage": int(completed / total * 100) if total > 0 else 0
        }

💡 执行引擎的核心功能：1) 按计划执行任务 2) 管理任务状态 3) 收集和存储结果 4) 跟踪执行进度
