客服Agent进化论 ⑦

槽位+记忆：别让Agent失忆

你有没有被客服机器人逼疯过？订个花要回答8个问题，修个空调要填10项信息——感觉像在填高考志愿表！前面的Skill都是"一轮式"的：用户说一句，Skill处理完就结束。但真实业务中，订花需要商品+数量+地址，报修需要型号+故障+时间，这些信息不可能一次说完。本篇介绍SlotFillingSkill——让多轮对话像聊天一样自然，而不是审问。

💡 如果你看过之前的《客服Agent实战系列》，应该接触过基础的槽位提取。本篇是加强版，我们来聊聊怎么把"提取槽位"升级成"多轮对话引导"，让信息收集像聊天一样自然。

1什么是槽位填充？从一个订花场景说起

先来看一个真实的订花对话：

🌷 理想的订花对话

用户：我要订花
Agent：好的，您想订购什么花？
用户：玫瑰吧
Agent：好的，玫瑰花要多少朵？
用户：99朵
Agent：好的，99朵玫瑰花束。请告诉我配送地址？
用户：送到望京SOHO T1
Agent：✅ 订单已确认：99朵玫瑰花束，配送地址：望京SOHO T1。我们会尽快为您配送！

这个对话的核心就是槽位填充——用户的每一句话都在"填表格"，但Agent引导得很自然，用户感觉不到在填表格。

对比一下糟糕的体验：

😱 糟糕的订花对话（审问式）

用户：我要订花
Agent：请提供以下信息：1.商品名称 2.数量 3.配送地址
用户：玫瑰
Agent：请提供数量
用户：99朵
Agent：请提供配送地址
用户：望京SOHO
Agent：订单已确认

区别在哪？前者是引导，后者是审问。前者每次只问一个问题，后者让用户一次性填所有信息。前者用自然的口语，后者用冷冰冰的模板。本篇就是要教你怎么做到"引导式"槽位填充。

2槽位填充基本模型

槽位填充的核心思想很简单：定义需要收集哪些信息（槽位），然后一步步引导用户填满。

图1：槽位填充基本模型

这个模型的关键要素：

要素说明订花场景示例
意图用户想做什么事order（订花）
槽位定义完成该意图需要哪些信息product、quantity、address
槽位提取从用户输入中识别并填入槽位"玫瑰" → product
引导策略缺什么问什么，一次只问一个缺quantity → "要多少朵？"
完成判定所有必填槽位都填好了吗？3个槽位全填 = 下单

看似简单，但做起来有几个坑：用户可能一句话说多个槽位、可能答非所问、可能中途改变主意。这些我们后面会聊。

4SlotFillingSkill核心实现

讲了这么多理论，来看代码实现。SlotFillingSkill 继承自 BaseSkill，核心逻辑集中在 execute() 方法中：

Python
import re
from typing import Dict, Any, List
from skills.base import BaseSkill, SkillResult


class SlotFillingSkill(BaseSkill):
    """槽位填充Skill - 处理多轮对话中的信息收集"""

    def __init__(self, config: Dict[str, Any], dialog: Any):
        self.config = config
        self.dialog = dialog

    @property
    def name(self) -> str:
        return "slot_filling"

    @property
    def description(self) -> str:
        return "槽位填充Skill - 多轮对话中收集订单所需信息"

    @property
    def triggers(self) -> List[str]:
        return ["订花", "买花", "订购", "下单", "订一束", "我要订", "购买"]

    @property
    def priority(self) -> int:
        return 8

    def can_handle(self, user_input: str, context: Dict[str, Any]) -> float:
        score = super().can_handle(user_input, context)
        slots = context.get("slots", {})
        dialog_state = context.get("dialog", {}).get("state", "")

        if dialog_state == "ORDER_COMPLETE":
            return 0.0

        if context.get("intent") == "order":
            score = max(score, 0.9)
        if slots.get("intent") == "order" and not slots.get("address"):
            score = max(score, 0.95)
        return score

来看核心的 execute() 方法——这是槽位填充的大脑：

Python
def execute(self, user_input: str, context: Dict[str, Any]) -> SkillResult:
    # Step 1: 标记意图
    self.dialog.fill_slot("intent", "order")

    # Step 2: 尝试提取商品
    products = [
        ("玫瑰花", "玫瑰花束"), ("玫瑰", "玫瑰花束"),
        ("百合", "百合花束"),
        ("康乃馨", "康乃馨花束"),
        ("向日葵", "向日葵花束"),
        ("郁金香", "郁金香花束"),
        ("花束", "花束"), ("鲜花", "鲜花"),
        ("花", "鲜花")
    ]
    for keyword, name in products:
        if keyword in user_input:
            self.dialog.fill_slot("product", name)
            break

    # Step 3: 尝试提取数量
    qty_match = re.search(r'(\d+)(?:朵|枝|束|个|份)', user_input)
    if qty_match:
        self.dialog.fill_slot("quantity", qty_match.group(1) + "朵")

    # Step 4: 尝试提取地址
    addr_match = re.search(
        r'(?:送到|运往|发往|地址是)([\u4e00-\u9fa5]+[^\s，,。]{2,20})',
        user_input
    )
    if addr_match:
        self.dialog.fill_slot("address", addr_match.group(1))

    # Step 5: 检查缺失的槽位
    slots = self.dialog.slots
    missing = self.dialog.missing_slots(["product", "quantity", "address"])

    # Step 6: 根据缺失情况引导
    if not slots.get("product"):
        return SkillResult(
            success=True,
            response="好的，您想订购什么？请告诉我商品名称（如玫瑰花、百合花等）。",
            data={"missing": missing, "slots": slots},
            confidence=0.8
        )

    if not slots.get("quantity"):
        return SkillResult(
            success=True,
            response=f"好的，{slots['product']}要多少？（如99朵、52朵）",
            data={"missing": missing, "slots": slots},
            confidence=0.8
        )

    if not slots.get("address"):
        return SkillResult(
            success=True,
            response=f"好的，已为您预订 {slots['quantity']} {slots['product']}。请告诉我配送地址。",
            data={"missing": missing, "slots": slots},
            confidence=0.8
        )

    # Step 7: 所有槽位填满 → 完成订单
    self.dialog.set_state("ORDER_COMPLETE")
    response_text = (
        f"✅ 订单已确认：{slots['quantity']} {slots['product']}，"
        f"配送地址：{slots['address']}。我们会尽快为您配送！"
    )
    response_data = {"slots": dict(slots), "order_created": True}
    for key in ["product", "quantity", "address", "location", "intent"]:
        self.dialog.slots.pop(key, None)
    return SkillResult(
        success=True,
        response=response_text,
        data=response_data,
        confidence=1.0
    )

代码逻辑分7步：
Step 1：标记意图为"order"
Step 2-4：用正则和关键词匹配提取槽位值
Step 5：检查还缺哪些槽位
Step 6：根据缺失槽位生成引导话术——缺product问商品，缺quantity问数量，缺address问地址
Step 7：所有槽位填满，确认订单并清理

5DialogManager：槽位的"账本"

你可能会问：槽位存在哪？答案是 DialogManager——对话管理器，它是所有槽位的"账本"。

Python
class DialogManager:
    """对话管理器 - 支持多轮对话、槽位填充、上下文管理"""

    def __init__(self, max_history: int = 20):
        self.history: List[Dict] = []
        self.max_history = max_history
        self.slots: Dict[str, str] = {}    # 槽位存储
        self.state: str = "INIT"            # 对话状态
        self.entities: List[Dict] = []     # 历史实体

    def fill_slot(self, slot_name: str, value: str):
        """填入槽位"""
        self.slots[slot_name] = value

    def get_slot(self, slot_name: str) -> Optional[str]:
        """获取槽位值"""
        return self.slots.get(slot_name)

    def missing_slots(self, required: List[str]) -> List[str]:
        """检查哪些必填槽位还没填"""
        return [s for s in required if s not in self.slots]

    def set_state(self, state: str):
        """更新对话状态"""
        self.state = state

    def get_context(self) -> Dict:
        """获取完整上下文"""
        return {
            "history": self.history,
            "slots": self.slots,
            "entities": self.entities,
            "state": self.state
        }

关键方法：

方法作用何时调用
fill_slot()填入/更新一个槽位每次从用户输入中提取到信息时
missing_slots()检查哪些必填槽位缺失决定下一句该引导什么
set_state()更新对话状态订单完成时设为 ORDER_COMPLETE
get_context()获取完整上下文Harness构建context时

6多轮对话引导的5个技巧

槽位填充的核心不是技术，而是引导技巧。以下是我总结的5个实战技巧：

技巧1：一次只问一个问题

用户的认知带宽有限。同时问3个问题，用户大概率会漏答。每次只问一个，用户的回答率会高很多。

Bash
# ❌ 错误：一次问多个问题
"请提供商品名称、数量和配送地址"

# ✅ 正确：一次只问一个
"好的，您想订购什么花？"

技巧2：用用户的语言说话

不要说"请提供商品信息"，要说"您想订购什么花？"。不要说"请提供配送地址"，要说"送到哪里？"。

Bash
# ❌ 错误：机械模板
"请填写以下字段：商品名称、数量"

# ✅ 正确：自然口语
"好的，99朵玫瑰花束。配送地址是？"

技巧3：展示已填信息，给用户确认感

当有多个槽位已填时，告诉用户"已为您预订99朵玫瑰花束"——这既是确认，也是在给用户信心。

技巧4：支持一句话多槽位

用户可能说"我要99朵玫瑰送到望京SOHO"，代码需要能同时提取product、quantity、address三个槽位。这在当前实现中已经支持了——因为我们在每轮都会检查所有槽位。

技巧5：自然过渡，不要机械跳转

当一个槽位填满后，不要突然切换话题。用"好的"、"没问题"等过渡词，然后自然地引导下一个槽位。

Bash
# ❌ 错误：机械跳转
Agent: 请告诉我商品
User: 玫瑰
Agent: 请告诉我数量

# ✅ 正确：自然过渡
Agent: 好的，玫瑰花要多少？（如99朵、52朵）

这5个技巧的核心就是把用户当人看。用户不是在填表格，是在和一个人对话。你的Agent越像人，用户的体验就越好。

7can_handle：让Router在对的时机选择SlotFilling

你可能会问：多轮对话中，Router怎么知道该继续用SlotFillingSkill而不是其他Skill？答案在 can_handle() 方法中：

Python
def can_handle(self, user_input: str, context: Dict[str, Any]) -> float:
    score = super().can_handle(user_input, context)
    slots = context.get("slots", {})
    dialog_state = context.get("dialog", {}).get("state", "")

    # 订单已完成，不再处理
    if dialog_state == "ORDER_COMPLETE":
        return 0.0

    # 意图是订花，直接打高分
    if context.get("intent") == "order":
        score = max(score, 0.9)

    # 已经在订花流程中且地址未填，强制打最高分
    if slots.get("intent") == "order" and not slots.get("address"):
        score = max(score, 0.95)

    return score

关键逻辑：

  • 如果对话状态是 ORDER_COMPLETE：返回0分，不再处理
  • 如果意图是 order：打0.9分，优先处理
  • 如果已经在订花流程中且地址未填：打0.95分，确保继续用SlotFilling而不是跳转到其他Skill

这就是状态感知的路由——Router不仅看用户当前输入，还看对话历史和已填槽位，做出更聪明的选择。

8本篇总结：槽位填充的3个核心思想

核心思想1：引导而非审问
一次只问一个问题，用自然口语，给用户确认感。

核心思想2：状态驱动
通过DialogManager的状态和槽位，让对话有记忆、有方向、有终点。

核心思想3：容错与灵活
支持一句话多槽位提取，支持跳步，支持答非所问的重新引导。

2用户记忆系统架构

用户记忆系统的设计目标很明确：让每个用户都有一个"档案"，记录他们的一切。

图1：用户记忆系统架构

这个架构分三层：

层级组件职责
存储层UserMemory持久化存储用户的所有数据
数据层Profile/Preference/History/Segment分别存储画像、偏好、历史、分群
应用层Greet/Recommend/Summary/Segment基于记忆实现个性化功能

核心设计思想：记忆不是一个功能，而是一个系统。它需要跨对话、跨会话、跨设备持久化。用户今天和Agent聊的内容，下周再来时Agent应该能记得。

4UserMemory核心实现

来看 UserMemory 的核心代码：

Python
import json
import time
import os
from typing import Dict, List, Optional


class UserMemory:
    """用户记忆系统 - 存储用户画像、历史交互、偏好"""

    def __init__(self, storage_file: str = "data/user_memory.json"):
        self.storage_file = storage_file
        self.users: Dict[str, Dict] = {}
        self._load()

    def _load(self):
        """从文件加载用户数据"""
        try:
            if os.path.exists(self.storage_file):
                with open(self.storage_file, 'r', encoding='utf-8') as f:
                    self.users = json.load(f)
        except (json.JSONDecodeError, IOError):
            self.users = {}

    def _save(self):
        """保存用户数据到文件"""
        os.makedirs(os.path.dirname(self.storage_file) or '.', exist_ok=True)
        with open(self.storage_file, 'w', encoding='utf-8') as f:
            json.dump(self.users, f, ensure_ascii=False, indent=2)

    def get_user(self, user_id: str) -> Dict:
        """获取用户档案，不存在则创建"""
        if user_id not in self.users:
            self.users[user_id] = self._create_default_user(user_id)
            self._save()
        return self.users[user_id]

    def _create_default_user(self, user_id: str) -> Dict:
        """创建默认用户档案"""
        return {
            "user_id": user_id,
            "created_at": time.time(),
            "profile": {
                "name": None,
                "phone": None,
                "level": "normal",
                "tags": []
            },
            "preferences": {
                "language": "zh-CN",
                "notification": True
            },
            "history": {
                "total_conversations": 0,
                "total_orders": 0,
                "last_interaction": None,
                "common_intents": []
            },
            "segments": [],
            "custom_data": {}
        }

关键方法解析：

  • get_user()：获取用户档案，如果不存在则自动创建默认档案
  • _load() / _save()：文件持久化，确保数据不丢失
  • _create_default_user()：为新用户创建标准化档案

5更新画像与记录交互

有了存储，接下来就是更新和记录。UserMemory提供了几个关键方法：

Python
def update_profile(self, user_id: str, **kwargs):
    """更新用户画像字段"""
    user = self.get_user(user_id)
    for key, value in kwargs.items():
        if key in user["profile"]:
            user["profile"][key] = value
    self._save()

def add_tag(self, user_id: str, tag: str):
    """给用户添加标签"""
    user = self.get_user(user_id)
    if tag not in user["profile"]["tags"]:
        user["profile"]["tags"].append(tag)
    self._save()

def record_interaction(self, user_id: str, intent: str,
                       user_input: str, bot_response: str):
    """记录一次交互"""
    user = self.get_user(user_id)
    user["history"]["total_conversations"] += 1
    user["history"]["last_interaction"] = {
        "time": time.time(),
        "intent": intent,
        "user_input": user_input,
        "bot_response": bot_response
    }
    if intent not in user["history"]["common_intents"]:
        user["history"]["common_intents"].append(intent)
    # 只保留最近10个意图
    user["history"]["common_intents"] = \
        user["history"]["common_intents"][-10:]
    self._save()

三个方法各司其职：
update_profile()：更新姓名、手机等画像信息
add_tag()：打标签，如"鲜花爱好者"、"VIP客户"
record_interaction()：记录每次对话的意图和内容，用于统计和推荐

这些方法会在Harness的 chat() 流程中被调用——每次对话结束后，Harness会自动把交互记录到UserMemory中。

6MemorySkill：让记忆为对话服务

有了数据存储，接下来就是让记忆服务于对话。这就是 MemorySkill 的职责：

Python
from typing import Dict, Any, List
from skills.base import BaseSkill, SkillResult


class MemorySkill(BaseSkill):
    """记忆Skill - 查询和更新用户画像"""

    def __init__(self, config: Dict[str, Any], memory: Any):
        self.config = config
        self.memory = memory

    @property
    def name(self) -> str:
        return "memory"

    @property
    def description(self) -> str:
        return "记忆Skill - 查询用户信息、更新用户画像"

    @property
    def triggers(self) -> List[str]:
        return ["我的信息", "我的资料", "我的等级", "会员", "个人信息"]

    @property
    def priority(self) -> int:
        return 4

    def can_handle(self, user_input: str, context: Dict[str, Any]) -> float:
        return super().can_handle(user_input, context)

    def execute(self, user_input: str, context: Dict[str, Any]) -> SkillResult:
        user_id = context.get("user_id", "anonymous")
        user_summary = self.memory.get_user_summary(user_id)
        segment = self.memory.build_user_segment(user_id)

        return SkillResult(
            success=True,
            response=f"您的账户信息：{user_summary}",
            data={
                "user_summary": user_summary,
                "segment": segment
            },
            confidence=0.9
        )

MemorySkill很简单——它的核心逻辑都在UserMemory中。Skill的职责是触发和调用，而UserMemory负责数据和逻辑。

def build_user_segment(self, user_id: str) -> str:
    """构建用户分群标签"""
    user = self.get_user(user_id)
    score = 0
    if user["profile"]["level"] == "vip":
        score += 3
    elif user["profile"]["level"] == "premium":
        score += 2
    score += min(user["history"]["total_orders"] // 5, 3)
    if score >= 5:
        return "high_value"
    elif score >= 3:
        return "medium_value"
    return "normal"

def get_user_summary(self, user_id: str) -> str:
    """生成用户摘要"""
    user = self.get_user(user_id)
    segment = self.build_user_segment(user_id)
    profile = user["profile"]
    history = user["history"]
    parts = []
    if profile["name"]:
        parts.append(f"用户：{profile['name']}")
    parts.append(f"等级：{profile['level']}")
    parts.append(f"分群：{segment}")
    parts.append(f"累计对话：{history['total_conversations']}次")
    parts.append(f"累计订单：{history['total_orders']}个")
    if history["last_interaction"]:
        last_time = time.strftime("%Y-%m-%d %H:%M",
                                 time.localtime(history["last_interaction"]["time"]))
        parts.append(f"上次交互：{last_time}")
    return " | ".join(parts)

9本篇总结：UserMemory的3个核心思想

核心思想1：持久化记忆
用户数据跨会话、跨设备持久化存储，不会因为一次对话结束就丢失。

核心思想2：分层存储
画像、偏好、历史、分群分层管理，每一层职责清晰。

核心思想3：记忆驱动对话
记忆不是存档，而是服务于问候、推荐、分群等应用，让对话更智能。
