对话式口语训练

英语学习Agent系列第05篇 | 口语练习

口语是英语学习中最具挑战性的部分之一。缺乏对话伙伴、害怕犯错、不知道如何改进——这些都是常见的痛点。我们将构建一个对话式口语训练系统，让学习者可以随时随地进行英语对话练习，并获得即时反馈和纠正。

01 对话场景设计

定义各种日常对话场景，让学习者在不同情境下练习口语：

python
from enum import Enum class ConversationScenario(Enum): GREETING = "问候" ORDERING_FOOD = "点餐" SHOPPING = "购物" TRAVEL = "旅行" JOB_INTERVIEW = "面试" DISCUSSION = "讨论" APPOINTMENT = "预约" COMPLAINT = "投诉" class ScenarioManager: def __init__(self): self.scenarios = { "GREETING": { "description": "日常问候和自我介绍", "level": "A1", "opening": "Hi! How are you today?", "target_expressions": ["Nice to meet you", "How are you", "I'm fine, thank you"] }, "ORDERING_FOOD": { "description": "在餐厅点餐", "level": "A2", "opening""Can I take your order?", "target_expressions": ["I'd like", "Could I have", "With fries"] }, "SHOPPING": { "description": "购物场景对话", "level": "B1", "opening": "Welcome to our store! Can I help you?", "target_expressions": ["How much is this", "Do you have", "Can I try it on"] }, "TRAVEL": { "description": "旅行相关对话", "level": "B1", "opening": "Good morning! Where are you heading today?", "target_expressions": ["I'd like a ticket", "How long does it take", "Where is"] }, "JOB_INTERVIEW": { "description": "求职面试", "level": "C1", "opening": "Good afternoon. Thank you for coming today. Please tell me about yourself.", "target_expressions": ["I have experience in", "My strengths are", "I am proficient in"] } } def get_scenario(self, name): return self.scenarios.get(name.upper(), None) def list_scenarios(self): return[{ "name": k, "description": v["description"], "level": v["level"] } for k, v in self.scenarios.items()]

02 对话引擎实现

使用Ollama模拟对话伙伴，支持多轮对话：

python
import ollama import json class ConversationEngine: def __init__(self, model="llama3:8b"): self.model = model self.messages = [] self.scenario = None self.turn_count = 0 def start_conversation(self, scenario): self.scenario = scenario self.messages = [] self.turn_count = 0 system_prompt = f""" 你是一位专业的英语对话练习伙伴。请在"{scenario['description']}"场景下与用户进行自然对话。 要求： 1. 使用{scenario['level']}级别的英语 2. 保持对话自然流畅，不要太机械 3. 根据用户的回答做出合适的回应 4. 不要主动结束对话，除非用户明确表示结束 5. 适当引导用户使用目标表达：{scenario['target_expressions']} """ self.messages.append({ "role": "system", "content": system_prompt }) self.messages.append({ "role": "assistant", "content": scenario["opening"] }) return scenario["opening"] def respond(self, user_input): self.messages.append({ "role": "user", "content": user_input }) response = ollama.chat( model=self.model, messages=self.messages ) reply = response["message"]["content"] self.messages.append({ "role": "assistant", "content": reply }) self.turn_count += 1 return reply def end_conversation(self): return{ "scenario": self.scenario["description"], "turn_count": self.turn_count, "total_messages": len(self.messages) }

03 口语评估与反馈

对用户的口语表达进行评估，提供即时反馈和改进建议：

python
import ollama import json class SpeakingEvaluator: def __init__(self, model="llama3:8b"): self.model = model def evaluate_response(self, user_input, scenario, target_expressions): prompt = f""" 请评估用户在"{scenario}"场景下的英语口语表达： 用户输入：{user_input} 需要评估的维度： 1. 语法准确性（0-10分） 2. 词汇丰富度（0-10分） 3. 表达自然度（0-10分） 4. 目标表达使用（是否使用了这些表达：{target_expressions}） 请提供： 1. 综合评分（0-100分） 2. 具体的语法错误和纠正建议 3. 更地道的表达方式 4. 鼓励性反馈 请以JSON格式输出： {{ "score": 综合评分, "grammar_score": 语法得分, "vocabulary_score": 词汇得分, "fluency_score": 流畅度得分, "grammar_errors": [{{"error": "错误内容", "correction": "纠正后", "explanation": "解释"}}], "improvement_suggestions": ["建议1", "建议2", "建议3"], "better_expressions": ["更好的表达1", "更好的表达2"], "encouragement": "鼓励性话语" }} """ response = ollama.chat( model=self.model, messages=[{ "role": "user", "content": prompt }] ) try: return json.loads(response["message"]["content"]) except json.JSONDecodeError: return{ "score": 0, "error": "评估失败，请重试" } def generate_summary(self, conversation_history, evaluations): history_text = "\n".join( [f"{m['role']}: {m['content']}" for m in conversation_history if m["role"] != "system"] ) prompt = f""" 请为以下对话生成口语练习总结： 对话内容： {history_text} 评估记录： {json.dumps(evaluations, ensure_ascii=False)} 请以JSON格式输出： {{ "overall_score": 平均分, "strengths": ["优点1", "优点2"], "weaknesses": ["不足1", "不足2"], "key_improvements": ["重点改进1", "重点改进2"], "practice_suggestions": ["练习建议1", "练习建议2", "练习建议3"], "new_vocabulary": ["新单词1", "新单词2", "新单词3"] }} """ response = ollama.chat( model=self.model, messages=[{ "role": "user", "content": prompt }] ) try: return json.loads(response["message"]["content"]) except json.JSONDecodeError: return{"error": "总结生成失败"}

04 口语学习流程

python
class SpeakingPractice: def __init__(self): self.scenario_manager = ScenarioManager() self.conversation_engine = ConversationEngine() self.evaluator = SpeakingEvaluator() self.evaluations = [] self.is_active = False def start_practice(self, scenario_name): scenario = self.scenario_manager.get_scenario(scenario_name) if not scenario: return{"error": "场景不存在"} opening_line = self.conversation_engine.start_conversation(scenario) self.is_active = True self.evaluations = [] return{ "status": "started", "scenario": scenario["description"], "opening": opening_line, "target_expressions": scenario["target_expressions"] } def speak(self, user_input): if not self.is_active: return{"error": "请先开始练习"} reply = self.conversation_engine.respond(user_input) evaluation = self.evaluator.evaluate_response( user_input, self.conversation_engine.scenario["description"], self.conversation_engine.scenario["target_expressions"] ) self.evaluations.append(evaluation) return{ "reply": reply, "evaluation": evaluation, "turn": self.conversation_engine.turn_count } def end_practice(self): if not self.is_active: return{"error": "没有正在进行的练习"} summary = self.evaluator.generate_summary( self.conversation_engine.messages, self.evaluations ) conversation_info = self.conversation_engine.end_conversation() self.is_active = False return{ "status": "ended", "conversation_info": conversation_info, "summary": summary } def list_scenarios(self): return self.scenario_manager.list_scenarios()

⚠️ 常见问题

1. 对话不自然：优化system prompt，让模型更像真人对话

2. 评估不准确：增加评估维度或使用更强大的模型

3. 对话过长导致回复变慢：限制对话轮数或启用流式输出（参考【本地大模型知识库系列】第08篇）

4. 缺少语音识别：可以集成Whisper实现语音输入（参考【本地大模型知识库系列】第11篇）
