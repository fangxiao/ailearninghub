语法是英语学习的骨架。传统语法学习往往是零散的知识点记忆，缺乏系统性。我们将使用知识图谱来构建语法知识点之间的依赖关系，让学习更有逻辑性。

01 构建语法知识图谱

使用NetworkX构建语法知识点的依赖关系图谱：

python
import networkx as nx import json class GrammarKnowledgeGraph: def __init__(self): self.graph = nx.DiGraph() self._build_graph() def _build_graph(self): grammar_topics = { "基础句型": { "description": sorted(self.get_next_topics(topic)): self._dfs_path(successor, visited, path)

02 语法点讲解与练习生成

使用Ollama生成语法点的详细讲解和练习题：

python
import ollama import json class GrammarTutor: def __init__(self, model="llama3:8b"): self.model = model self.graph = GrammarKnowledgeGraph() def explain_topic(self, topic): prerequisites = self.graph.get_prerequisites(topic) prompt = f""" 你是一位专业的英语语法老师。请详细讲解语法点"{topic}"： 要求： 1. 简明扼要的定义和核心规则 2. 常见用法和注意事项 3. 至少3个典型例句（中英文对照） 4. 常见错误和纠正方法 5. 如果有前置知识"{prerequisites}"，请简要回顾相关内容 请以JSON格式输出： {{ "topic": "语法点名称", "definition": "定义", "rules": ["规则1", "规则2", "规则3"], "examples": [{{"english": "例句", "chinese": "翻译", "explanation": "解析"}}], "common_mistakes": [{{"wrong": "错误句子", "correct": "正确句子", "reason": "原因"}}], "difficulty": "难度等级(1-5)" }} """ response = ollama.chat( model=self.model, messages=[{ "role": "user", "content": prompt }] ) try: return json.loads(response["message"]["content"]) except json.JSONDecodeError: returnNone def generate_exercises(self, topic, count=5): prompt = f""" 你是一位专业的英语语法老师。请为语法点"{topic}"生成{count}道练习题。 题型包括： 1. 选择题 2. 填空题 3. 改错题 请以JSON格式输出： {{ "topic": "{topic}", "exercises": [ {{ "type": "choice/fill/error", "question": "题目内容", "options": ["选项A", "选项B", "选项C", "选项D"], "answer": "正确答案", "explanation": "答案解析" }} ] }} """ response = ollama.chat( model=self.model, messages=[{ "role": "user", "content": prompt }] ) try: return json.loads(response["message"]["content"]) except json.JSONDecodeError: returnNone def check_answer(self, exercise, user_answer): is_correct = user_answer.strip().lower() == exercise["answer"].strip().lower() return{ "correct": is_correct, "correct_answer": exercise["answer"], "explanation": exercise["explanation"] }

03 语法学习流程

python
class GrammarLearner: def __init__(self): self.tutor = GrammarTutor() self.completed_topics = set() self.current_topic = None def start_topic(self, topic): prerequisites = self.tutor.graph.get_prerequisites(topic) for prereq in prerequisites: if prereq not in self.completed_topics: return{ "status": "error", "message": f"需要先学习前置知识：{prerequisites}" } self.current_topic = topic explanation = self.tutor.explain_topic(topic) exercises = self.tutor.generate_exercises(topic) return{ "status": "success", "topic": topic, "explanation": explanation, "exercises": exercises["exercises"] if exercises else [] } def submit_answer(self, exercise, answer): return self.tutor.check_answer(exercise, answer) def complete_topic(self, topic): self.completed_topics.add(topic) next_topics = self.tutor.graph.get_next_topics(topic) return{ "message": f"恭喜完成'{topic}'！", "next_topics": next_topics, "completed_count": len(self.completed_topics) } def get_learning_progress(self): total_topics = len(self.tutor.graph.graph.nodes) completed_count = len(self.completed_topics) return{ "completed_topics": list(self.completed_topics), "total_topics": total_topics, "progress": round(completed_count / total_topics * 100, 2) }

⚠️ 常见问题

1. 知识点依赖关系不正确：可以手动调整知识图谱中的prerequisites配置

2. 练习题难度不合适：在generate_exercises中添加难度参数

3. 进度数据丢失：添加进度持久化存储（参考第02篇的WordBook实现）

4. 讲解内容太复杂：优化prompt，要求更简洁易懂的解释
