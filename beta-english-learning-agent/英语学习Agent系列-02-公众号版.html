词汇是英语学习的基础。一个好的单词本不仅要展示单词的释义，还要根据记忆曲线算法合理安排复习时间，让学习事半功倍。

01 记忆曲线算法

艾宾浩斯记忆曲线告诉我们，人的记忆会随着时间逐渐遗忘。通过在遗忘临界点进行复习，可以有效强化记忆。我们实现一个简化的间隔重复算法：

python
import datetime from enum import Enum class ReviewInterval(Enum): NEW = 0 ONE_DAY = 1 THREE_DAYS = 3 ONE_WEEK = 7 TWO_WEEKS = 14 ONE_MONTH = 30 THREE_MONTHS = 90 class WordCard: def __init__(self, word, definition, example=""): self.word = word self.definition = definition self.example = example self.level = ReviewInterval.NEW self.last_review = None self.next_review = None self.correct_count = 0 self.wrong_count = 0 def review(self, is_correct): self.last_review = datetime.datetime.now() if is_correct: self.correct_count += 1 self._level_up() else: self.wrong_count += 1 self._level_down() self._update_next_review() def _level_up(self): levels = [ReviewInterval.NEW, ReviewInterval.ONE_DAY, ReviewInterval.THREE_DAYS, ReviewInterval.ONE_WEEK, ReviewInterval.TWO_WEEKS, ReviewInterval.ONE_MONTH, ReviewInterval.THREE_MONTHS] current_idx = levels.index(self.level) self.level = levels[min(current_idx + 1, len(levels)-1)] def _level_down(self): self.level = ReviewInterval.NEW def _update_next_review(self): self.next_review = datetime.datetime.now() \ + datetime.timedelta(days=self.level.value) def is_due_for_review(self): if self.next_review is None: returnTrue return datetime.datetime.now() >= self.next_review

02 使用Ollama生成单词卡

利用大模型生成单词的详细解释和例句（关于Ollama的安装和使用，请参考【本地大模型知识库系列】第02篇）：

python
import ollama import json class WordCardGenerator: def __init__(self, model="llama3:8b"): self.model = model def generate_word_card(self, word): prompt = f""" 你是一个英语词汇专家。请为单词 "{word}" 生成详细的学习卡片，包括： 1. 音标（英音和美音） 2. 词性 3. 中文释义（多个含义用分号分隔） 4. 常用搭配（至少3个） 5. 例句（至少2个，中英文对照） 6. 记忆技巧 请以JSON格式输出，不要包含其他内容。格式如下： {{ "word": "单词", "phonetic": "音标", "part_of_speech": "词性", "definitions": ["释义1", "释义2"], "collocations": ["搭配1", "搭配2", "搭配3"], "examples": [{{"english": "英文例句", "chinese": "中文翻译"}}], "memory_tip": "记忆技巧" }} """ response = ollama.chat( model=self.model, messages=[{ "role": "user", "content": prompt }] ) try: data = json.loads(response["message"]["content"]) return data except json.JSONDecodeError: returnNone # 使用示例 generator = WordCardGenerator() card = generator.generate_word_card("ubiquitous") if card: print(json.dumps(card, ensure_ascii=False, indent=2))

03 单词本管理

创建一个单词本管理器，支持添加单词、获取待复习单词、记录复习结果：

python
import json import os class WordBook: def __init__(self, file_path="word_book.json"): self.file_path = file_path self.cards = {} self._load() def _load(self): if os.path.exists(self.file_path): with open(self.file_path, 'r', encoding='utf-8') as f: data = json.load(f) for word, card_data in data.items(): card = WordCard(word, card_data["definition"], card_data["example"]) card.level = ReviewInterval[card_data["level"]] card.correct_count = card_data["correct_count"] card.wrong_count = card_data["wrong_count"] self.cards[word] = card def _save(self): data = {} for word, card in self.cards.items(): data[word] = { "definition": card.definition, "example": card.example, "level": card.level.name, "correct_count": card.correct_count, "wrong_count": card.wrong_count } with open(self.file_path, 'w', encoding='utf-8') as f: json.dump(data, f, ensure_ascii=False, indent=2) def add_word(self, word, definition, example=""): if word not in self.cards: self.cards[word] = WordCard(word, definition, example) self._save() def get_due_cards(self, limit=10): due_cards = [card for card in self.cards.values() if card.is_due_for_review()] return due_cards[:limit] def record_review(self, word, is_correct): if word in self.cards: self.cards[word].review(is_correct) self._save()

⚠️ 常见问题

1. 生成的单词卡格式错误：检查Ollama是否正常运行（参考【本地大模型知识库系列】第02篇）

2. 复习间隔不合理：调整ReviewInterval的时间间隔

3. 单词本数据丢失：确保文件保存路径有写入权限

4. 生成速度慢：使用更小的模型或添加缓存机制（参考【本地大模型知识库系列】第10篇）
