01 项目结构整理

首先，让我们整理项目结构，确保所有模块文件组织清晰：

bash
english-learning-agent/ ├── main.py # 主入口，启动Gradio界面 ├── requirements.txt # 依赖列表 ├── vocabulary_reviewer.py # 词汇学习模块（第02篇） ├── grammar_learner.py # 语法学习模块（第03篇） ├── reading_learner.py # 阅读理解模块（第04篇） ├── speaking_practice.py # 口语练习模块（第05篇） ├── writing_coach.py # 写作辅助模块（第06篇） ├── knowledge_graph.py # 知识图谱（第03篇） ├── data/ # 数据目录 │ ├── vocabulary.db # 单词数据库 │ └── grammar_topics.json # 语法知识点 └── chroma_db/ # 向量数据库（第04篇）

创建requirements.txt文件，列出所有必要的依赖：

bash
ollama==0.1.35 gradio==4.36.1 langchain==0.1.14 chromadb==0.4.22 networkx==3.2.1 textstat==0.7.3 sqlalchemy==2.0.29 python-dotenv==1.0.1

02 一键启动脚本

创建一键启动脚本，方便用户快速运行：

bash
#!/bin/bash echo "🚀 启动英语学习Agent..." if ! command -v ollama &>/dev/null; then echo "❌ Ollama未安装，请先安装Ollama（参考【本地大模型知识库系列】第02篇）" exit 1 fi if ! ollama list 2>/dev/null; then echo "🔄 启动Ollama服务..." ollama serve & sleep 5 fi if ! ollama list 2>/dev/null | grep -q "llama3"; then echo "📥 下载llama3模型..." ollama pull llama3 fi echo "🌐 启动Web界面..." python3 main.py

03 Docker容器化部署

对于需要在服务器上稳定运行的场景，可以使用Docker进行容器化部署。创建Dockerfile：

dockerfile
FROM python:3.11-slim WORKDIR /app RUN apt-get update && apt-get install -y \ curl \ && rm -rf /var/lib/apt/lists/* RUN curl -fsSL https://ollama.com/install.sh | sh COPY requirements.txt . RUN pip install --no-cache-dir -r requirements.txt COPY . . EXPOSE 7860 CMD ["bash", "-c", "ollama serve & sleep 5 && python main.py"]

创建docker-compose.yml文件：

yaml
version: '3.8' services: english-learning-agent: build: . ports: - "7860:7860" volumes: - ./data:/app/data - ./chroma_db:/app/chroma_db - ~/.ollama:/root/.ollama restart: "always"

优化维度 优化策略 预期效果
