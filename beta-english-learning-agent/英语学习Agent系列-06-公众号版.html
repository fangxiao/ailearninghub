英语学习Agent系列第06篇 | 写作辅助

写作是英语学习中最考验综合能力的部分。从构思到表达，从语法到用词，每一步都需要精心打磨。我们将构建一个AI写作教练，帮助学习者完成从选题、大纲、草稿到润色的全流程写作指导。

01 写作主题生成与大纲

使用Ollama生成写作主题和大纲：

python
import ollama import json class TopicGenerator: def __init__(self, model="llama3:8b"): self.model = model def generate_topics(self, category, level="B1", count=5): prompt = f""" 请为英语学习者生成{count}个{category}主题的写作题目，难度级别为{level}。 要求： 1. 题目要有明确的写作方向 2. 适合{level}级别的词汇和语法要求 3. 每个题目附带简短的写作建议 请以JSON格式输出： {{ "topics": [ {{ "title": "题目名称", "description": "题目描述", "suggestion": "写作建议" }} ] }} """ response = ollama.chat( model=self.model, messages=[{ "role": "user", "content": prompt }] ) try: return json.loads(response["message"]["content"]) except json.JSONDecodeError: returnNone def generate_outline(self, topic, level="B1"): prompt = f""" 请为写作题目"{topic}"生成一个详细的大纲，难度级别为{level}。 大纲结构： 1. 引言（介绍主题） 2. 主体段落（分点论述） 3. 结论（总结观点） 要求： 1. 每个部分要有明确的要点 2. 提供关键句型和词汇建议 3. 适合{level}级别的写作要求 请以JSON格式输出： {{ "topic": "{topic}", "outline": [ {{ "section": "章节名称", "points": ["要点1", "要点2", "要点3"], "key_sentences": ["句型1", "句型2"], "key_vocabulary": ["词汇1", "词汇2", "词汇3"] }} ], "tips": ["写作提示1", "写作提示2"] }} """ response = ollama.chat( model=self.model, messages=[{ "role": "user", "content": prompt }] ) try: return json.loads(response["message"]["content"]) except json.JSONDecodeError: returnNone

02 作文评估与润色

对用户的作文进行全面评估，并提供润色建议：

python
import ollama import json class WritingEvaluator: def __init__(self, model="llama3:8b"): self.model = model def evaluate_essay(self, essay, topic=None): topic_text = topic if topic else"未指定" prompt = f""" 请评估以下英语作文： 题目：{topic_text} 作文内容： {essay} 评估维度（每项0-20分）： 1. 内容完整性 2. 组织结构 3. 语法准确性 4. 词汇多样性 5. 表达流畅性 请提供： 1. 各维度得分和总分（0-100分） 2. 具体的语法错误和纠正 3. 词汇替换建议（提升表达丰富度） 4. 结构优化建议 5. 整篇作文的修改版本 请以JSON格式输出： {{ "total_score": 总分, "scores": {{ "content": 内容得分, "structure": 结构得分, "grammar": 语法得分, "vocabulary": 词汇得分, "fluency": 流畅性得分 }}, "grammar_errors": [{{"original": "原句", "corrected": "修改后", "explanation": "解释"}}], "vocabulary_suggestions": [{{"original": "原词", "suggestion": "建议词", "context": "使用场景"}}], "structure_suggestions": ["建议1", "建议2"], "revised_essay": "修改后的作文", "comments": "综合评价" }} """ response = ollama.chat( model=self.model, messages=[{ "role": "user", "content": prompt }] ) try: return json.loads(response["message"]["content"]) except json.JSONDecodeError: return{"error": "评估失败，请重试"} def get_paragraph_feedback(self, paragraph): prompt = f""" 请对以下段落进行分析，并提供改进建议： 段落内容： {paragraph} 请分析： 1. 语法问题 2. 用词是否恰当 3. 句子结构是否清晰 4. 连贯性如何 请提供具体的修改建议和优化后的版本。 请以JSON格式输出： {{ "issues": ["问题1", "问题2"], "suggestions": ["建议1", "建议2"], "improved_version": "优化后的段落", "explanation": "修改说明" }} """ response = ollama.chat( model=self.model, messages=[{ "role": "user", "content": prompt }] ) try: return json.loads(response["message"]["content"]) except json.JSONDecodeError: return{"error": "分析失败，请重试"}

03 写作辅助流程

python
class WritingCoach: def __init__(self): self.topic_generator = TopicGenerator() self.evaluator = WritingEvaluator() self.current_topic = None self.current_outline = None def suggest_topics(self, category, level="B1"): return self.topic_generator.generate_topics(category, level) def get_outline(self, topic, level="B1"): outline = self.topic_generator.generate_outline(topic, level) if outline: self.current_topic = topic self.current_outline = outline return outline def evaluate_essay(self, essay): return self.evaluator.evaluate_essay(essay, self.current_topic) def get_paragraph_feedback(self, paragraph): return self.evaluator.get_paragraph_feedback(paragraph) def improve_sentence(self, sentence): prompt = f""" 请优化以下英语句子，使其更地道、更流畅： 原句：{sentence} 请提供： 1. 优化后的句子（保持原意） 2. 优化说明 请以JSON格式输出： {{ "original": "{sentence}", "improved": "优化后的句子", "explanation": "优化说明" }} """ response = ollama.chat( model=self.evaluator.model, messages=[{ "role": "user", "content": prompt }] ) try: return json.loads(response["message"]["content"]) except json.JSONDecodeError: return{"error": "优化失败，请重试"}

⚠️ 常见问题

1. 生成的题目太难或太简单：调整level参数或优化prompt中的难度描述

2. 作文评估不准确：增加评估维度或使用更强大的模型

3. 修改版本偏离原意：在prompt中强调"保持原意不变"

4. 长文评估速度慢：限制作文长度或启用流式输出（参考【本地大模型知识库系列】第08篇）
