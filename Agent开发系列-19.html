动态调整

任务分解和执行引擎讲完了。但在实际执行中，计划往往赶不上变化。子任务可能失败、外部条件可能改变、用户需求可能调整——这时候就需要动态调整。

💡 核心观点：好的执行系统不是一条道走到黑，而是能根据实际情况灵活应变。动态调整让Agent系统更健壮。

1回滚机制

当某个子任务失败时，需要回滚已完成的操作，保持系统状态一致。

pythonclass RollbackManager:
    def __init__(self):
        self.history = []

    def save_state(self, state):
        self.history.append(state)

    def rollback(self):
        if not self.history:
            return None
        state = self.history.pop()
        return state

    def handle_failure(self, failed_task, context):
        # 回滚到上一个稳定状态
        previous_state = self.rollback()
        if previous_state:
            context.restore(previous_state)
        return {
            "action": "replan",
            "reason": f"Task {failed_task} failed"
        }

2降级策略

当理想方案不可用时，自动切换到备选方案。

pythonclass FallbackStrategy:
    def __init__(self):
        self.fallbacks = {
            "image_gen": ["dalle", "stable_diffusion", "placeholder"],
            "search": ["google", "bing", "cache"],
            "llm": ["gpt-4", "gpt-3.5", "local"]
        }

    def execute_with_fallback(self, capability, func, *args):
        fallbacks = self.fallbacks.get(capability, [])
        for fallback in fallbacks:
            try:
                result = func(fallback, *args)
                return result
            except Exception as e:
                continue
        raise Exception(f"All fallbacks failed for {capability}")

3用户干预

pythonclass DynamicExecutor:
    def execute_with_intervention(self, plan):
        for batch in plan:
            for task in batch:
                result = self.check_and_execute(task)
                if result.get("needs_intervention"):
                    user_choice = self.request_user_input(result)
                    if user_choice == "abort":
                        return {"status": "aborted"}
                    elif user_choice == "modify":
                        modified_plan = self.replan(result)
                        return self.execute_with_intervention(modified_plan)

    def check_and_execute(self, task):
        # 高风险操作需要用户确认
        if task.get("risk_level") > 0.7:
            return {"needs_intervention": True, "task": task}
        return self.execute_task(task)

💡 动态调整的三板斧：回滚恢复状态、降级切换方案、干预交给用户。这三招让系统面对意外时也能稳如泰山。

协作模式设计

单个Agent能力有限，遇到复杂任务时需要多个Agent协作。这一篇，我们来看多Agent协作的基本模式。

💡 核心观点：多Agent协作不是简单地把多个Agent串起来，而是要设计好协作模式，让它们各司其职、高效配合。

1三种协作模式

模式特点适用场景
流水线顺序执行，上游输出是下游输入内容生产、数据处理
主从一个主Agent协调多个从Agent复杂任务分解、团队管理
对等所有Agent平等协作，共享目标头脑风暴、方案评审

2流水线模式

pythonclass PipelineOrchestrator:
    def __init__(self):
        self.stages = []

    def add_stage(self, name, agent):
        self.stages.append({"name": name, "agent": agent})

    def execute(self, initial_input):
        context = {"input": initial_input}
        for stage in self.stages:
            agent = stage["agent"]
            result = agent.run(context)
            context[stage["name"]] = result
            context["input"] = result  # 传递给下一个阶段
        return context

pipeline = PipelineOrchestrator()
pipeline.add_stage("research", research_agent)
pipeline.add_stage("write", write_agent)
pipeline.add_stage("review", review_agent)
result = pipeline.execute("AI发展趋势")

3主从模式

pythonclass MasterSlaveOrchestrator:
    def __init__(self, master_agent):
        self.master = master_agent
        self.slaves = {}

    def register_slave(self, name, agent, capabilities):
        self.slaves[name] = {
            "agent": agent,
            "capabilities": capabilities
        }

    def execute(self, task):
        subtasks = self.master.decompose(task)
        results = {}
        for subtask in subtasks:
            slave_name = self.master.assign(subtask, self.slaves)
            slave = self.slaves[slave_name]["agent"]
            results[subtask["id"]] = slave.run(subtask)
        return self.master.aggregate(results)

4对等模式

pythonclass PeerToPeerOrchestrator:
    def __init__(self):
        self.peers = []
        self.message_bus = MessageBus()

    def add_peer(self, agent):
        self.peers.append(agent)
        agent.set_message_bus(self.message_bus)

    def execute(self, goal):
        # 每个peer独立工作，通过message bus共享进展
        threads = []
        for peer in self.peers:
            t = Thread(target=peer.work, args=(goal,))
            threads.append(t)
            t.start()
        for t in threads:
            t.join()
        return self.message_bus.get_all_results()

💡 协作模式选择指南：流水线适合线性流程、主从适合任务分配、对等适合并行探索。根据场景选对模式，协作效率翻倍。
