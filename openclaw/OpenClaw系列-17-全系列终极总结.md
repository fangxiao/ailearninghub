## 💡 核心知识点速查

### AI Agent 核心概念

**定义：**
```
AI Agent = 能感知、思考、行动的 AI 系统
```

**核心循环：**
```
感知 → 思考 → 行动 → 反思
  ↑                      ↓
  └──────────────────────┘
```

**关键能力：**
- 感知：理解用户输入和环境信息
- 思考：推理决策，选择行动方案
- 行动：调用工具，执行任务
- 反思：评估结果，优化策略

<br/>

---

### Skill 开发核心

**Skill 结构：**
```
my-skill/
├── skill.yaml      # 配置文件（名称、版本、依赖）
├── main.py         # 代码文件（核心逻辑）
└── README.md       # 文档文件（使用说明）
```

**开发流程：**
```
设计 → 开发 → 测试 → 部署
```

**关键原则：**
- 单一职责：一个Skill解决一个问题
- 清晰接口：输入输出定义明确
- 完整文档：使用说明详细清晰

<br/>

---

### 记忆系统架构

**四层记忆：**

| 类型 | 作用 | 存储 | 容量 |
|------|------|------|------|
| 工作记忆 | 当前对话 | 内存 | 有限 |
| 对话记忆 | 历史会话 | 数据库 | 无限 |
| 知识记忆 | 向量检索 | 向量库 | 无限 |
| 技能记忆 | 流程定义 | 文件 | 无限 |

**关键策略：**
- Token 管理：压缩、摘要、优先级
- RAG 检索：向量化、语义搜索
- 长期记忆：持久化、索引、优化

<br/>

---

| 能力 | 要点 |
