## 💡 核心知识点速查

### Skill 开发

```
Skill结构：
├── skill.yaml    # 配置文件
├── skill.py      # 代码文件
└── README.md     # 文档文件

开发流程：
需求分析 → 环境准备 → 编写配置 → 编写代码 → 测试调试 → 部署分享
```

<br/>

### 工作流设计

```
核心概念：
• 任务节点（Node）：每个步骤
• 连接线（Edge）：执行顺序
• 变量（Variable）：数据传递
• 条件（Condition）：分支选择
• 循环（Loop）：重复执行

设计原则：
• 单一职责
• 清晰的输入输出
• 完善的错误处理
```

<br/>

### 多Agent协作

```
协作模式：
• 流水线模式：顺序执行
• 主从模式：任务分发
• 对等模式：平等协作

关键机制：
• 消息传递
• 共享记忆
• 冲突解决
```

<br/>

### 工具集成

```
Function Calling流程：
用户提问 → LLM分析 → 调用工具 → 执行工具 → 返回结果 → 生成回复

安全措施：
• 权限控制
• 敏感信息保护
• 审计日志
```
