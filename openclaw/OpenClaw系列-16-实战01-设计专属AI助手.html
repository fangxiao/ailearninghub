一、需求分析：你想要什么助手？

1.1助手能做什么？

OpenClaw的能力范围：

✅ 可以做：
• 文件操作（读写、整理、搜索）
• 网络搜索（获取信息）

• 文档处理（PDF、Word、Excel）

❌ 不能做：
• 控制物理设备（除非有API）

二、功能设计：MVP vs 完整版

2.1什么是MVP？

MVP = Minimum Viable Product（最小可行产品）

MVP原则：
• 只做最核心的功能
• 快速上线验证
• 根据反馈迭代
• 避免过度设计

2.2小王助手的功能规划

MVP版本（第1周）：

核心功能：
✅ 日程提醒
   - 连接飞书日历
   - 每天早上8点推送今日日程
   - 会议前15分钟提醒

✅ 简单待办
   - 添加待办事项
   - 标记完成
   - 每日回顾

✅ 基础交互
   - 飞书私聊
   - 自然语言理解

完整版（第2周及以后）：

扩展功能：
• 会议纪要（语音转文字）
• 邮件摘要（连接邮箱）
• 智能建议（根据习惯推荐）
• 项目追踪（进度管理）
• 周报生成（自动汇总）

四、架构设计：单Agent vs 多Agent

4.1架构选项

选项A：单Agent（推荐新手）

┌─────────────────────────────┐
│         主Agent             │
│  ┌─────────────────────┐   │
│  │  意图识别            │   │
│  │  日程/待办/提醒      │   │
│  │  对话管理            │   │
│  └─────────────────────┘   │
└─────────────────────────────┘

优点：
✅ 简单易懂
✅ 调试方便
✅ 资源占用少

缺点：
❌ 功能耦合
❌ 扩展性一般

选项B：多Agent（进阶）

┌──────────┐    ┌──────────┐    ┌──────────┐
│ 调度Agent │───→│ 日程Agent │    │ 待办Agent │
└──────────┘    └──────────┘    └──────────┘
     ↓
┌──────────┐
│ 提醒Agent │
└──────────┘

优点：
✅ 模块化
✅ 易扩展
✅ 可并行

缺点：
❌ 复杂度高
❌ 通信成本

选项C：工作流模式（推荐）

┌─────────────────────────────────────┐
│            主工作流                  │
│  ┌─────┐   ┌─────┐   ┌─────┐      │
│  │意图  │→ │路由  │→ │执行  │      │
│  │识别  │   │分发  │   │任务  │      │
│  └─────┘   └─────┘   └─────┘      │
└─────────────────────────────────────┘

优点：
✅ 清晰的流程
✅ 易于调试
✅ 平衡复杂度

4.2小王的架构选择

选择：工作流模式

yaml# 架构设计
architecture:
  模式: 工作流
  
  组件:
    - 入口: 飞书消息接收
    - 意图识别: LLM分类
    - 路由分发: 根据意图分发
    - 任务执行: 对应Skill
    - 结果返回: 飞书消息
  
  数据流:
    用户消息 → 意图识别 → 路由 → Skill执行 → 返回结果

from dataclasses import dataclass
from datetime import datetime
from typing import Optional

@dataclass
class Todo:
    """待办事项"""
    id: str                    # 唯一ID
    title: str                 # 标题
    description: str           # 描述
    status: str                # pending/completed
    priority: str              # high/medium/low
    due_date: Optional[datetime]  # 截止时间
    created_at: datetime       # 创建时间
    completed_at: Optional[datetime]  # 完成时间
    tags: list[str]            # 标签

# 存储结构（SQLite）
"""
CREATE TABLE todos (
    id TEXT PRIMARY KEY,

    description TEXT,
    status TEXT DEFAULT 'pending',
    priority TEXT DEFAULT 'medium',

    completed_at TIMESTAMP,

);
"""
