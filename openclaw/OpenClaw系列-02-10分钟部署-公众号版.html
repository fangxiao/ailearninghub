10分钟在电脑上跑起你的第一个 AI 智能体：OpenClaw 本地部署实操指南

零基础上手 · 从软件安装到执行第一个自动化任务，不卡壳避坑全流程

AI 智能体上手指南 | 宝玉风格通俗复盘 | 大前端工程师

很多朋友想在自己的电脑上体验真正的 AI 智能体（Agent），但在网上一搜教程，常常被一堆专有名词劝退：

❌ “先配置 Python 虚拟环境与 Conda 依赖”
❌ “拉取 Docker 镜像并修改 Nginx 反向代理”
❌ “编译 C++ 运行库与 Node.js 环境变量”

其实，体验一个能帮你干活的 AI 智能体，根本不需要这么折腾。

今天我们用最通俗的大白话，拆解如何用 10 分钟在 Windows 或 Mac 电脑上把开源智能体框架 OpenClaw（代号：小龙虾） 跑起来，并让它帮你完成第一个实战任务。

01 电脑配置要求（普通办公本都能跑）

因为智能体的“大脑思考”主要是通过云端大模型接口完成的，所以它对你本地电脑的硬件要求非常亲民：

• 操作系统：Windows 10 / 11、macOS 10.14+ 均可；

• 内存要求：4GB 内存就能跑，8GB 以上更流畅；

• 硬盘空间：预留 2GB 可用空间即可（不需要独立显卡！）。

02 3 种安装方式怎么选？

OpenClaw 提供了三种使用形态，大家可以根据自己的需求对号入座：

安装形态 适合人群 核心优势
1. 微信小程序版 新手尝鲜、手机临时使用 0 门槛免安装，微信扫码即用
2. 桌面客户端 (推荐) 日常办公、需要处理本地文件 可视化界面，能读写本地文件夹并执行自动化
3. 开源源码部署 开发者二次开发与深度定制 可自由修改源码、扩展私有插件

03 桌面客户端安装实操（只需 3 步）

这里我们以绝大多数人日常最需要的桌面客户端为例：

第一步 · 下载安装包：进入官方发布页面，Windows 用户下载 .exe 安装包，Mac 用户下载 .dmg 安装包；

第二步 · 双击安装与启动：像安装日常软件一样点击“下一步”完成安装，首次启动会看到一个干净的智能体控制台；

第三步 · 填入大模型 Key：在设置里填入你常用的大模型 API Key（支持 DeepSeek、Kimi、Claude 或通义千问，几十块钱能用好几个月）。

04 跑通你的第一个自动化任务

装好之后，它和普通 Chat 聊天机器人最大的区别是：智能体可以调用工具帮你实际操作电脑。

你可以直接在对话框输入一条实际指令进行测试：

Agent 实战指令 Prompt
# 智能体任务指令示范（直接粘贴到对话框） “帮我检查 ~/Downloads 文件夹，把里面所有的 PDF 电子书移动到 ~/Documents/Ebooks 目录，并按文件大小生成一份 Markdown 归档清单。”

💡 你会看到它一步一步执行：感知任务 ➔ 列出下载文件夹文件 ➔ 过滤出 PDF ➔ 创建目标目录 ➔ 批量归档移动 ➔ 输出统计表格。整个过程完全不需要你手动拖拽！
