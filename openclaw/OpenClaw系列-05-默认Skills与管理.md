## 一、OpenClaw内置Skill

### 1.1 文件操作Skill

#### 📁 文件整理

**功能：** 自动整理文件，按类型分类

**使用示例：**

> 输入：帮我把桌面整理一下
> 输出：✅ 整理完成！已分类 **15** 个文件
> • 图片 → Images/ (**5** 个)
> • 文档 → Documents/ (**8** 个)
> • 其他 → Others/ (**2** 个)

**支持的操作：**

• ✅ 按类型分类
• ✅ 按日期分类
• ✅ 批量重命名
• ✅ 删除重复文件

#### 📄 文档处理

**功能：** 处理各种文档格式

**支持格式：**

• **PDF** 转 **Word** /图片
• **Word** 转 **PDF**
• 图片压缩
• 文字提取（**OCR**）

**使用示例：**

> 输入：把这个PDF转换成Word
> 输出：✅ 转换完成！已保存为：report.docx

#### 🔍 文件搜索

**功能：** 快速搜索文件

**搜索能力：**

• 按文件名搜索
• 按内容搜索（支持 **PDF**、**Word**）
• 按日期范围搜索
• 按文件大小搜索

**使用示例：**

> 输入：找到所有包含"财务"的文档
> 输出：找到 **7** 个文件：
> • 财务报表.docx
> • 财务制度.pdf
> • **2026** 年财务总结.xlsx
> ...

## 二、如何查看内置Skill

### 2.1 图形界面查看

#### 操作步骤：

**Step 1：打开 OpenClaw**

双击桌面图标，进入主界面

**Step 2：进入Skills 管理**

点击右上角"Skill"按钮（拼图图标）

**Step 3：查看Skill 列表**

左侧显示所有已安装 Skill，右侧显示Skill 详情

#### Skill分类：

> **文件操作（8个）：**
> 文件整理、文档处理、文件搜索、压缩解压、批量重命名、重复检测、格式转换、备份恢复
>
> **网络工具（5个）：**
> 网页搜索、网页收藏、下载管理、链接检测、网络测速
>
> **信息处理（6个）：**
> 文本翻译、摘要生成、数据分析、AI对话、格式化、校对润色
>
> **自动化（4个）：**
> 定时任务、批量处理、工作流、监控提醒

### 2.2 命令行查看

#### 查看所有Skill：

```bash
openclaw skills list
```

#### 查看Skill 详情：

```bash
openclaw skills info Skill名
```

#### 示例输出：

> Skill 名称：file-organizer
> 版本：**1.0.0**
> 描述：自动整理文件，按类型分类
> 作者：**OpenClaw** 官方
> 状态：✅ 已启用
> 使用次数：**23** 次

## 四、Skills 管理

### 4.1 启用/禁用 Skill

#### 为什么要禁用？

• 减少资源占用
• 避免Skill冲突
• 提高响应速度

#### 操作方法：

**方法1：图形界面**

Skills 管理 → 找到Skill → 切换开关

**方法2：命令行**

```bash
openclaw skills enable Skill名    # 启用
openclaw skills disable Skill名   # 禁用
```

### 4.2 更新 Skill

#### 检查更新：

Skills 管理 → 点击"检查更新"按钮

#### 更新单个Skill：

```bash
openclaw skills update Skill名
```

#### 更新所有Skill：

```bash
openclaw skills update --all
```

#### 自动更新：

设置 → Skill 设置 → 开启"自动更新"

### 4.3 删除Skill

#### ⚠️ 注意：

• 内置Skill无法删除
• 删除后数据可能丢失
• 建议先备份配置

#### 操作方法：

**方法1：图形界面**

Skills 管理 → 找到Skill → 点击"卸载"

**方法2：命令行**

```bash
openclaw skills uninstall Skill名
```

### 4.4 Skill 配置

#### 可配置项：

• API密钥
• 默认参数
• 快捷方式
• 权限设置

#### 配置方法：

Skills 管理 → 找到Skill → 点击"配置"

#### 示例（天气查询）：

> **默认城市：** 北京
> **温度单位：** 摄氏度
> **语言：** 中文
> **自动定位：** 是

## 五、Skill 使用技巧

### 5.1 快速调用Skill

#### 方法1：自然语言

直接说出需求，**OpenClaw** 自动识别：

> "北京今天天气怎么样？"
> → 自动调用天气查询Skill
>
> "帮我把这个PDF转成Word"
> → 自动调用文档处理Skill

#### 方法2：Skill名+参数

明确指定Skill：

> "天气 北京"
> "翻译 Hello world"
> "搜索 AI新闻"

#### 方法3：快捷键

为常用Skill 设置快捷键：

> Ctrl/Cmd + Shift + T → 天气查询
> Ctrl/Cmd + Shift + S → 网页搜索
> Ctrl/Cmd + Shift + N → 新建笔记

### 5.2 Skill组合使用

#### 场景1：收集资料

> **步骤1：** 搜索Skill → 查找相关文章
> **步骤2：** 收藏Skill → 保存网页内容
> **步骤3：** 摘要Skill → 生成文章摘要
> **步骤4：** 整理Skill → 归类到笔记

#### 场景2：制作报告

> **步骤1：** 数据Skill → 分析Excel数据
> **步骤2：** 图表Skill → 生成可视化图表
> **步骤3：** 写作Skill → 生成文字报告
> **步骤4：** 排版Skill → 美化格式

### 5.3 常见问题

#### 问题1：Skill调用失败？

• 检查Skill是否已启用
• 检查网络连接
• 检查API Key配置
• 查看错误日志

#### 问题2：找不到想要的Skill？

• 搜索不同关键词
• 浏览分类目录
• 查看社区推荐
• 自己开发Skill

#### 问题3：Skill太多，响应慢？

• 禁用不常用Skill
• 清理过期Skill
• 优化Skill 配置
