## 一、龙虾不是吃的，是你的"数字员工"

### 1.1 别被名字吓到

"龙虾"是 **OpenClaw** 的昵称。

为什么叫龙虾？因为它的logo是个红色的钳子。  
就像苹果公司的标志是个苹果一样简单。

**那OpenClaw到底是什么？**

> 一个能真正干活的AI助手。

<br/>

### 1.2 它和ChatGPT有什么区别？

**ChatGPT：**

• 你问："怎么整理文件？"
• 它答："你可以先分类，再建立文件夹..."
• **结果**：还是得你自己动手

<br/>

**OpenClaw：**

• 你说："帮我把桌面整理一下"
• 它说："好的，正在整理..."
• **结果**：10秒后，桌面真的整洁了！

<br/>

**核心区别：**

> ChatGPT给你建议，OpenClaw帮你干活。

<br/>

### 1.3 想象一下

如果你有个员工：

• 📧 你说"整理邮件"，它就去整理
• 📊 你说"做报表"，它就去制作
• 📁 你说"归档文件"，它就去分类
• 📝 你说"写周报"，它就去撰写

**24小时待命，从不抱怨，不犯错，不要求加薪。**

这不是科幻，这是OpenClaw。

## 五、怎么开始？3种方式

### 方式1：微信小程序（最快，2分钟）

**适合：** 完全新手，想马上体验

**步骤：**

1. 打开微信
2. 搜索"QClaw"
3. 授权登录
4. 开始使用

**优点：** 0门槛，免费体验

**缺点：** 功能简单，不能操作本地文件

<br/>

### 方式2：桌面应用（推荐，5分钟）

**适合：** 日常使用，需要处理本地文件

**步骤：**

1. 访问 openclaw.ai 下载
2. 双击安装（Windows/Mac）
3. 首次配置
4. 开始使用

**优点：** 功能完整，响应快

**缺点：** 需要下载安装

<br/>

### 方式3：命令行（极客，5分钟）

**适合：** 开发者，喜欢折腾

**步骤：**

brew install openclaw  
openclaw init  
openclaw start

**优点：** 完全自定义，最新版本

**缺点：** 有学习曲线
