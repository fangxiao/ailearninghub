本地大模型知识库系统

一、系统概述

本系统是一个基于本地大模型的知识库问答系统，具有以下特点：

1. 数据不出域：所有数据都存储在本地，不会上传到云端
2. 隐私安全：用户数据和知识库内容完全由用户掌控
3. 离线可用：不需要网络连接即可使用（模型下载后）
4. 灵活扩展：支持多种文档格式，易于添加新的知识库内容

二、技术架构

系统采用以下技术栈：

1. 大模型：使用Ollama部署的本地大模型，如Llama3、Qwen、DeepSeek等
2. 向量数据库：使用ChromaDB存储文档向量，实现高效的语义检索
3. Embedding：使用Sentence-Transformers将文本转换为向量表示
4. 框架：使用LangChain进行大模型和向量检索的编排
5. Web界面：使用Flask构建Web服务，提供用户友好的交互界面

三、核心功能

1. 文档加载：支持PDF、Word、Markdown、纯文本等多种格式
2. 文档分割：自动将长文档分割为合适大小的片段
3. 向量存储：将文档片段转换为向量并存储到向量数据库
4. 语义检索：根据用户查询检索最相关的文档片段
5. 智能问答：结合检索结果和大模型生成准确的回答

四、使用流程

1. 准备文档：将需要导入的文档放入data/docs目录
2. 构建知识库：运行main.py或通过Web界面重建知识库
3. 提问：通过命令行或Web界面向知识库提问
4. 获取答案：系统返回基于知识库的回答，并标注参考来源

五、配置说明

系统支持以下配置项：

- OLLAMA_MODEL：使用的大模型名称，默认为llama3:8b
- EMBEDDING_MODEL：使用的Embedding模型，默认为all-MiniLM-L6-v2
- CHROMA_DB_PATH：向量数据库存储路径，默认为./data/chroma_db
- DOCS_PATH：文档目录路径，默认为./data/docs
- MAX_DOC_LENGTH：文档片段最大长度，默认为500
- TOP_K_RESULTS：检索返回的最大结果数，默认为3
- SIMILARITY_THRESHOLD：相似度阈值，默认为0.7
