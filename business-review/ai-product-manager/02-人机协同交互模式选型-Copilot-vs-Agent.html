做 AI 功能不是非要放一个“右下角悬浮聊天气泡”。很多场景下，对话框反而是最低效的交互形态。

3 种核心交互形态深度对比

模式 交互特征 用户心智 典型案例
Chatbot 对话流 问答式、单向多轮、低结构化 “我问你答” ChatGPT, 智能客服
Copilot 嵌入式 内嵌在原有工作流中（快捷键/划选） “副驾驶帮我改” Notion AI, Github Copilot
Agent 全自主 给目标后自主规划拆解、调用工具 “我给目标你全干” Claude Code, 自动化爬虫

产品经理选型法则：如果是严肃创作（如写文档、做表格），优先采用 Copilot 划选呼出；如果是广域知识检索，采用 Chatbot；如果是多步骤批量审批与流转，采用 Agent 后台异步跑。
