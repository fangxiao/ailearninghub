不用买服务器、免备案：我是如何用 Cloudflare + GitHub 搭建独立知识库的？

实战经验复盘 · 零成本建站、微信正常访问与百度/谷歌收录指南

📝 通俗实战 (约 1800 字) 🏷️ 个人建站 / 零成本 / 免备案 / 微信访问 / 搜索收录 👨‍💻 作者：大前端工程师

如果你想为自己或团队搭建一个专门放技术文章、使用教程或业务资料的独立知识库，通常会遇到两个麻烦事：

一是成本高：每年要花几百上千块租云服务器；
二是流程繁琐：要在国内绑定域名，要在国内绑定域名，必须申请 ICP 备案、提交各种资料审核并等上一两周。

但对于文档和博客这类“别人主要用来看、不需要经常往数据库里存数据”的网站，其实完全不需要买云服务器，也不需要等待备案。

这次我们在上线 AI 学习智库（https://ailearning.top） 时，采用了一套非常轻便的方案：用 GitHub 存代码，用 Cloudflare 免费分发加速。全流程只花了几块钱买域名，当天就完成上线，并在微信和各大搜索引擎里跑通了全部流程。

把这套通俗好懂的搭建经验记录下来，分享给有同样需求的朋友。

01 为什么不需要买云服务器？

我们可以把建站理解为开店：

• 传统建站（买云服务器）：相当于你租了一间实体店面。不管今天有没有客人来，每个月都要交固定的房租和水电费，还得自己负责打扫和防盗；
• 现代静态建站（Cloudflare 托管）：相当于你把印刷好的手册，免费放在全球各地的公共服务台。有人想看时，就近的服务台直接把手册递给他，你不需要租店面，一分钱房租都不用掏。

02 如何做到让 166 篇文章打开不卡顿？

很多人建站喜欢装很多插件，导致网页打开很慢。我们做知识库时遵循了两个简单的原则：

1. 纯静态页面：不连复杂的数据库，直接把文章生成干净的 HTML 文件。打开网页时，就像看一张图片一样快；
2. 自动生成轻量目录索引：通过几行简单的 Python 脚本，把 166 篇文章的标题和简介提取出来，生成一个只有几十 KB 的小目录。读者在网页里搜文章或点分类时，在手机本地瞬间完成，完全不需要等待服务器慢慢查询。

03 微信里打开会不会被拦截？

这是很多人最关心的问题：“没办国内备案，在微信里点链接会不会弹警告？”

只要做好这三点，微信里就能正常顺畅打开：

1. 用正规的独立域名：花几块钱买个正经的域名（比如 .top 或 .com），不要用免费平台上那种长串的临时测试网址；
2. 内容干净合规：文章都是正规的技术分享与教程，不搞“强制关注公众号才能看”、“强制转发朋友圈才能看”这类微信严打的诱导行为；
3. 开通 https 安全锁：Cloudflare 会自动为域名配好免费的 SSL 安全证书，微信识别为安全链接后就会直接打开。
04 怎么让百度和 Google 能搜到你的网站？

网站建好后，如果别人搜不到，就像把店开在深山里。让搜索引擎主动来收录只需要做两件事：

graph TD A[网站自动生成地图 sitemap.xml] --> B[提交给 Google Search Console ➔ 自动抓取] A --> C[提交给 必应 Bing ➔ 一键同步] A --> D[提交给 百度 ➔ 用 API 接口先推送首页和分类]
• 自动生成网站地图 (sitemap.xml)：把网站所有文章的链接整理成一份标准清单（我们站一共 338 个链接）；
• 去 Google 和 Bing 提交：在 Google 站长后台填入 sitemap.xml，点提交就搞定了；Bing 更是支持直接从 Google 账号一键导入；
• 百度新站小技巧：新网站在百度提交地图时可能暂时没有配额，可以在百度的【API 提交】页面，用几行 Python 脚本把首页和主要分类链接直接推给百度，当天就能进入抓取队列。
05 怎么看每天有多少人来访问？

不需要在网站里安装乱七八糟的统计插件，Cloudflare 仪表盘自带了流量看板：

• 每天有多少人看（独立访客数 UV、浏览量 PV）；
• 读者来自国内还是海外；
• 读者是用手机微信、电脑还是浏览器打开的。

全部自动统计，一目了然。

06 总结与建议

如果你也想搭建自己的技术专栏、产品使用手册或个人作品集，**建议优先考虑“GitHub + Cloudflare 边缘托管”这条路线**。

它不仅帮你省下了每年的服务器续费开销和维护精力，还能让你把 100% 的时间聚焦在最核心的事情上——写出真正有价值的内容。
