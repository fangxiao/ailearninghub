# AI科普系列 - 混知风格提纲（整合版）

## 📖 系列定位

**目标读者**：对AI好奇但不懂技术的普通人
**风格特点**：极简插图 + 吐槽口语 + 生活类比 + 短段落快节奏
**核心价值**：把复杂的AI概念，用"人话"讲清楚

**系列关系**：这是"AI学习三层楼"的第一层（入门层）
- 第一层：AI科普系列（本文）—— 用生活类比讲清楚基本概念
- 第二层：大模型原理系列 —— 深入理解Transformer、GPT等技术原理
- 第三层：客服Agent实战系列 —— 动手构建完整的AI应用

## 🗺️ 系列大纲（共12篇）

### 第一层：AI科普系列（入门）

**第01篇：AI到底是什么？—— 其实就是个"超级实习生"**
- 类比：把AI比作一个无所不能的实习生
- 核心概念：机器学习、深度学习、大模型的区别
- **深入学习**：《大模型原理系列 · 开篇》

**第02篇：大模型为什么能"说话"？—— 猜字游戏玩到极致**
- 类比：就像你发短信时输入法猜你下一个字
- 核心概念：自回归、Token、生成原理
- **深入学习**：《大模型原理系列 07 · GPT生成原理》

**第03篇：AI能理解我吗？—— 它只是"假装"懂你**

**第04篇：AI是怎么学习的？—— 题海战术的终极版**

- 类比：参数越多，AI就越聪明（但也越费电）

**第06篇：AI为什么会犯错？—— 它也会"考试翻车"**
- 类比：再聪明的学生也有粗心的时候

**第09篇：AI能聊天多久？—— 它的"短期记忆"有多长**

- 核心概念：上下文窗口、记忆机制、位置编码

**第10篇：怎么跟AI聊天？—— 学会"喂饭"很重要**

**第11篇：AI会取代我吗？—— 别慌，它是你的"超级外挂"**

## 🎨 混知风格设计规范

### 视觉风格
- **配色**：黑白为主，点缀鲜艳色（红、蓝、黄）
- **字体**：粗体大号字，像手写板书
- **插图**：SVG简笔画，极简线条，人物只有轮廓
- **布局**：大量留白，每段不超过3行，短句为主

### 语言风格
- **口语化**："咱们""说白了""就这么简单"
- **吐槽感**：适当加入幽默吐槽，拉近读者距离
- **类比优先**：每个概念都用生活类比解释
- **短段落**：每段1-2句话，节奏快，不拖沓

### 整合特色
- 每篇末尾添加"深入学习"和"动手实践"链接
- 底部导航展示完整的三层学习路径
- 与大模型原理系列、客服Agent实战系列相互呼应
