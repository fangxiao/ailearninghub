Prompt工程：让Bot有灵魂

数据模型是骨架，Prompt是灵魂。同一个Bot模型，换一个Prompt，效果可能天差地别。

很多人觉得Prompt就是"随便写几句提示词"。大错特错。Prompt工程是AI时代最重要的技能之一。

💡 核心观点：Prompt不是越详细越好，也不是越简洁越好。好的Prompt是有结构的、有层次的、能被模型理解的。Prompt工程的核心是"把你脑子里的东西，准确传达给AI"。

1Prompt的四个层次

一个完整的Prompt，通常包含这四个层次：

text# 第一层：角色定义
你是一个专业的Python后端工程师。

# 第二层：任务定义
你的职责是帮助用户优化代码、解释技术方案、review代码。

# 第三层：约束条件
1. 回答必须基于Python最佳实践
2. 代码必须包含类型注解
3. 复杂问题必须先分析再给出方案

# 第四层：输出格式
用Markdown格式回答，代码块要标注语言。

层层递进，缺一不可。没有角色定义，模型不知道以什么身份回答；没有任务定义，不知道要干什么；没有约束条件，可能跑偏；没有输出格式，可能给你一段没有标点的文字。

2myAgent的Prompt模板系统

上一节讲了Bot数据模型里的prompt_config。这节讲具体怎么实现变量替换。

python# backend/core/prompt.py
import re
from typing import Dict, Any

class PromptTemplate:
    # Prompt模板类，负责变量插值

    def __init__(self, template: str, config: Dict[str, Any]):
        self.template = template
        self.config = config

    def render(self, context: Dict[str, Any]) -> str:
        # 用正则匹配 {variable_name} 格式的变量
        result = self.template
        for match in re.finditer(r'\{(\w+)\}', self.template):
            var_name = match.group(1)
            # 优先级：context > config > default
            if var_name in context:
                value = context[var_name]
            elif var_name in self.config:
                value = self.config[var_name]
            else:
                value = f'{{{var_name}}}' # 保留原样
            result = result.replace(f'{{{var_name}}}', str(value))
        return result

使用示例：

python# 使用示例
template = "你是一个{bot_role}，服务于{company_name}公司。"
config = {
    "bot_role": "客服助手",
    "company_name": "某科技有限公司"
}

prompt = PromptTemplate(template, config)
print(prompt.render({}))
# 输出：你是一个客服助手，服务于某科技有限公司公司。

# 运行时覆盖
print(prompt.render({"company_name": "新公司"}))
# 输出：你是一个客服助手，服务于新公司。

3Few-shot示例管理

有时候，纯文字的Prompt不够用，需要示例来教模型什么是好的回答。

pythonclass Example:
    # 单个示例
    input: str
    output: str

class ExampleBank:
    # 示例库，支持动态选择
    examples: List[Example] = []

    def select(self, context: dict, k: int = 2) -> List[Example]:
        # 根据上下文选择最相关的k个示例
        # 可以用Embedding相似度，也可以用规则
        return self.examples[:k]

    def to_prompt(self, examples: List[Example]) -> str:
        # 转换为Prompt字符串
        lines = []
        for ex in examples:
            lines.append(f"输入：{ex.input}")
            lines.append(f"输出：{ex.output}")
        return"\n".join(lines)

示例管理的关键是按需选择。不是把所有示例都塞进Prompt，而是根据当前对话的上下文，选择最相关的几个。

4Prompt版本管理：不只是改文字

很多人忽略了Prompt的版本管理。但Prompt的每一次改动，都可能影响Bot的行为。

pythonclass PromptVersion(SQLModel, table=True):
    __tablename__ = "prompt_versions"

    id: str = Field(primary_key=True)
    bot_id: str = Field(foreign_key="bots.id")
    version: int

    system_prompt: str
    prompt_config: dict
    examples: List[Example] = Field(default=list)

    # 效果指标
    avg_rating: float = Field(default=0.0)  # 用户平均评分
    usage_count: int = Field(default=0)     # 使用次数

    created_at: datetime
    created_by: str
    changelog: str = ""

Prompt不是一次性写完就不管了，而是要持续优化。通过版本管理和效果追踪，可以量化每个Prompt版本的好坏。

💡 总结：Prompt是Bot的灵魂。好的Prompt有四个层次：角色、任务、约束、格式。myAgent通过PromptTemplate支持变量插值，通过ExampleBank支持Few-shot，通过PromptVersion支持版本追踪。Prompt工程是AI时代最重要的技能。
