一、核心概念总结

1.1Coding Agent vs 大模型

Coding Agent = 软件（Claude Code、通义灵码、Cursor 等）

大模型 = AI 能力（Claude 4、GPT-4.5、GLM-5 等）

关键区别： Claude Code 可配置多种模型，其他 Agent 多数固定模型

✅ Claude Code 的优势

1. 模型灵活
   - 可配置国内模型（GLM-5、通义千问）
   - 可配置国际模型（Claude 4、GPT-4.5）
   - 根据场景切换

2. 深度理解
   - 上下文窗口 200K tokens
   - 多文件协同
   - 代码库理解

3. 国内友好
   - 配国内模型无需代理
   - 中文支持完美
   - 价格便宜（用国内模型）

1.2五个核心操作

1. 代码生成

从无到有，快速实现

示例：
"用 Python 写一个用户注册函数，包含验证和错误处理"

2. 代码解释

理解原理，学习提升

示例：
"解释这段代码的原理，指出潜在问题"

3. Bug 修复

定位问题，快速解决

示例：
"这个函数报错 ZeroDivisionError，帮我修复"

4. 重构优化

提升质量，改善性能

示例：
"重构这个函数，提升可读性和性能"

5. 测试生成

保证质量，提高可靠性

示例：
"为这个函数生成单元测试，覆盖率 90%+"

1.3提示词技巧

黄金公式：

背景 + 任务 + 要求 + 示例 + 格式

示例：

【背景】我在做一个 Django 电商项目

【任务】写一个商品搜索 API

【要求】
- 支持关键词、价格区间筛选
- 支持分页（每页20条）
- 返回 JSON 格式

【示例】
请求：GET /api/products?keyword=iPhone&page=1
响应：{"products": [...], "total": 100}

【格式】
- 遵循 Django REST framework 规范

二、常见问题汇总

Q1：Claude Code 必须用 Claude 模型吗？

❌ 错误理解：Claude Code 只能用 Claude 模型

✅ 正确理解：
- Claude Code 是 Coding Agent 产品
- 可以配置不同模型
- 推荐国内用户配置 GLM-5 或通义千问

Q2：国内用户怎么用 Claude Code？

方案1（推荐）：
Claude Code + GLM-5（智谱）
- 注册 open.bigmodel.cn
- 免费 1000万 tokens
- 无需代理

方案2：
Claude Code + 通义千问（阿里）
- 注册 dashscope.aliyun.com
- 价格便宜
- 稳定可靠

Q3：免费吗？

✅ Claude Code：基础功能免费
✅ GLM-5：1000万 tokens 免费
✅ 通义千问：个人版免费
✅ CodeGeeX：完全免费

推荐免费组合：
Claude Code + GLM-5

Q4：Claude Code vs 通义灵码，选哪个？

通义灵码：
✅ 开箱即用
✅ 阿里云生态
✅ 企业支持
❌ 只能用通义千问

Claude Code：
✅ 模型灵活
✅ 可配置国内模型
✅ 功能强大
❌ 需要自己配置

建议：
- 想开箱即用：选通义灵码
- 想模型灵活：选 Claude Code

Q5：提示词写不好怎么办？

常见错误：
❌ 太简单："写个函数"
❌ 缺上下文：不给项目背景
❌ 矛盾要求：既要快又要省

改进方法：
✅ 用模板（背景+任务+要求+示例+格式）
✅ 分步提问（不要一次问太多）
✅ 提供约束条件
✅ 要求解释和对比

三、最佳实践

3.1工作流建议

日常开发流程：

1. 快速补全
   用 CodeGeeX 或 通义灵码
   - 行内补全
   - 快速编码

2. 复杂任务
   用 Claude Code + 国内模型
   - 代码生成
   - 重构优化
   - Bug 修复

3. 代码审查
   用 Claude Code
   - 分析代码质量
   - 找潜在问题
   - 优化建议

4. 测试和文档
   用 Claude Code
   - 生成测试用例
   - 生成 API 文档
   - 写 README

3.2模型选择策略

根据任务选模型：

简单补全：
→ GLM-5-Flash（快）
→ 通义千问-Turbo（便宜）

复杂推理：
→ Claude 4 Sonnet（最强）
→ GLM-5（国产最强）
→ 通义千问-Max（阿里最强）

长文本：
→ Claude 4（200K）
→ GLM-5（128K）

预算有限：
→ GLM-5（免费额度大）
→ 通义千问-Turbo（便宜）

3.3效率提升技巧

技巧1：建立提示词库

保存常用提示词模板：

templates/
├── code_generation.md
├── bug_fix.md
├── refactor.md
├── test_generation.md
└── documentation.md

需要时直接套用

技巧2：分步骤处理复杂任务

不要一次问太多，分步提问：

第1步："设计这个功能的架构"
第2步："实现核心代码"
第3步："添加错误处理"
第4步："写测试用例"
第5步："优化性能"

每步质量更高

技巧3：让 Claude 解释

不只是要代码，还要理解：

"写完代码后，请解释：
1. 为什么这样实现
2. 有什么替代方案
3. 优缺点是什么
4. 什么时候不适用"

加深理解，提升能力
