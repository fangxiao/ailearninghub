## 💡 核心知识点速查

### AI Coding 核心概念

**定义：**
```
AI Coding = AI 辅助编程
通过 AI 帮助你写代码、改代码、调试、重构
```

**Coding Agent 产品：**
```
✅ Claude Code - 模型灵活，功能全面
✅ 通义灵码 - 开箱即用，免费
✅ CodeGeeX - 完全免费
✅ Cursor - IDE 体验好
✅ GitHub Copilot - 生态成熟
```

**Claude Code 优势：**
```
1. 模型灵活 - 可配置国内外模型
2. 国内友好 - 用国内模型无需代理
3. 深度理解 - 200K tokens 上下文
4. 功能全面 - 5大核心能力
```

<br/>

---

### 5个核心操作

**1. 代码生成**
```
提示词：详细需求 + 风格要求 + 示例
效果：从0到1快速生成代码
```

**2. 代码解释**
```
提示词：解释这段代码的原理、流程、优缺点
效果：快速理解复杂代码
```

**3. Bug 修复**
```
提示词：错误信息 + 完整代码 + 预期行为
效果：快速定位和修复问题
```

**4. 重构优化**
```
提示词：重构目标 + 分步进行 + 保持功能
效果：提升代码质量和性能
```

**5. 测试生成**
```
提示词：覆盖率要求 + 边界测试 + 异常测试
效果：自动生成完整测试用例
```

<br/>

---

### 提示词黄金公式

**公式：**
```
高质量提示词 = 背景 + 任务 + 要求 + 示例
```

**示例：**
```
【背景】我在做 Django 电商项目

【任务】实现商品搜索功能

【要求】
- 支持 Elasticsearch
- 支持关键词和价格区间筛选
- 使用 Redis 缓存

【示例】
输入：搜索"手机"，价格1000-3000
输出：匹配的商品列表
```

<br/>

---

### 最佳实践

**1. 提供详细上下文**
```
❌ "写个排序函数"
✅ "用 Python 写一个快速排序，时间复杂度 O(n log n)，支持逆序排列"
```

**2. 指定代码风格**
```
❌ "写个函数"
✅ "遵循 PEP 8 规范，使用类型注解，添加 docstring"
```

**3. 提供示例**
```
❌ "处理异常"
✅ "类似这样：try-except-finally，捕获 ValueError 和 TypeError"
```

**4. 分步进行**
```
❌ "重构这个大函数"
✅ "分3步：提取子函数 → 优化逻辑 → 添加注释"
```

**5. 验证结果**
```
✅ 让 AI 解释代码
✅ 生成测试用例
✅ 手动测试验证
```
