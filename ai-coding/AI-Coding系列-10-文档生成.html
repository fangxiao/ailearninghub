pythondef calculate_discount(user_level, amount):

AI 生成文档：

pythondef calculate_discount(user_level: str, amount: float) -> float:
    """
    根据用户等级计算折扣价格
    
    Args:
        user_level (str): 用户等级，可选值：
            - 'normal': 普通用户（无折扣）
            - 'silver': 银牌用户（95折）
            - 'gold': 金牌用户（9折）
            - 'platinum': 白金用户（85折）
        amount (float): 原始金额，必须为正数
    
    Returns:
        float: 折扣后的金额
    
    Raises:
        ValueError: 当 amount 为负数时
    
    Examples:
        >>> calculate_discount('gold', 100.0)
        90.0
        
        >>> calculate_discount('platinum', 200.0)
        170.0
    
    Note:
        - 未知等级按普通用户处理
        - 金额精度保留2位小数
    """
    if amount < 0:
        raise ValueError("金额不能为负数")
    
    discounts = {
        'normal': 1.0,      # 无折扣
        'silver': 0.95,     # 95折
        'gold': 0.9,        # 9折
        'platinum': 0.85    # 85折
    }
    
    result = amount * discounts.get(user_level, 1.0)
    return round(result, 2)

# 用户 API 文档

创建用户

接口地址： POST /api/users

参数名 类型 必填 说明

三、文档维护策略

3.1自动同步文档

问题： 代码改了，文档忘记更新

解决方案： CI/CD 自动检查

yaml# .github/workflows/doc-check.yml

name: Documentation Check

on: [push, pull_request]

jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      
      - name: Check docstrings
        run: |
          pip install pydocstyle
          pydocstyle app/
      
      - name: Check API docs
        run: |
          python scripts/check_api_docs.py
      
      - name: Generate docs
        run: |
          pip install sphinx
          cd docs && make html
