大模型原理系列 08

系列八 Scaling Law —— 为什么模型越大越聪明

我的观点：Scaling Law（缩放定律）是大模型时代最重要的发现之一。它告诉我们：模型效果会随着参数量、数据量、计算量的增加而可预测地提升。这不是玄学，而是有数学规律可循的。理解了Scaling Law，你就理解了为什么OpenAI要不断把模型做大。

先问大家一个问题

GPT-3有1750亿参数，GPT-4据说更多。

为什么要把模型做得这么大？

你可能会说："参数多，能力就强呗。"

但为什么参数多就能力强？有没有上限？——

答案在Scaling Law里。OpenAI在2020年发表的研究发现：模型效果和参数量、数据量、计算量之间存在幂律关系——可以预测！

0上期回顾：GPT是怎么生成的

上期我们讲了GPT的自回归生成：一个字一个字地预测，每次都基于前面的内容。

但还有一个问题：为什么GPT-3能生成得这么好？

答案：因为它够大。但"大"和"好"之间是什么关系？这就是Scaling Law要回答的问题。

1什么是Scaling Law？

Scaling Law是OpenAI在2020年发现的经验规律：

Scaling Law的核心公式

损失函数 L(N, D, C) ≈ L∞ + (N/N*)^(-αN) + (D/D*)^(-αD) + (C/C*)^(-αC)

其中：

• N = 参数量（Parameters）

• D = 数据量（Data size）

• C = 计算量（Compute）

简单说：模型效果（损失函数）会随着N、D、C的增加而下降，而且这个下降是可预测的——不是随机变好，而是有规律地变好。

生活中的类比

想象你在考试：

• 学习时间越长，成绩越好

• 练习题越多，成绩越好

• 脑子越聪明，成绩越好

Scaling Law就是发现了这三者和成绩之间的数学关系——不是"可能变好"，而是"一定会变好多少"。

2三个关键因素

Scaling Law告诉我们，模型效果取决于三个因素：

因素 含义 影响
参数量 N 模型"脑子"的大小 参数越多，能学到的模式越复杂
数据量 D 训练数据的规模 数据越多，见过的例子越多
计算量 C 训练时的总计算量 计算越多，学得越充分

老师：这三个因素哪个最重要？

小明：参数量？因为GPT-3就是因为参数多才厉害？

老师：其实三者要平衡。Scaling Law发现：给定计算预算，最优的参数量和数据量有一个固定比例。只增加参数不增加数据，效果提升会变慢。

3幂律关系：效果提升有规律

Scaling Law最惊人的发现是：效果提升遵循幂律（Power Law）。

这意味着：

  • 参数量增加10倍 → 损失下降固定比例
  • 数据量增加10倍 → 损失下降固定比例
  • 计算量增加10倍 → 损失下降固定比例

而且这个比例是可预测的！

图1：Scaling Law曲线——损失随参数量/数据量/计算量增加而下降，呈幂律关系

4为什么GPT-3有1750亿参数？

理解了Scaling Law，你就明白了为什么GPT-3要这么大。

OpenAI的计算：

  • 根据Scaling Law，要达到某个效果水平，需要多少参数？
  • 给定计算预算（训练成本），最优的参数量是多少？
  • 1750亿参数，是在当时计算预算下的最优选择

这不是拍脑袋决定的，而是根据Scaling Law计算出来的。

模型规模的演进

• GPT-1：1.17亿参数（2018）

• GPT-2：15亿参数（2019）

• GPT-3：1750亿参数（2020）

• GPT-4：未公开，估计万亿级别（2023）

规律：每个版本大约增加10倍参数。这不是巧合，而是Scaling Law告诉他们：要提升效果，就得这么增加。

5涌现现象：量变到质变

Scaling Law预测的是平均效果，但还有一个有趣的现象：涌现（Emergence）。

某些能力不是线性提升的，而是在达到某个规模后突然出现：

能力 小模型 大模型
简单问答 ✅ 能做 ✅ 做得更好
代码生成 ❌ 不行 ✅ 突然能做
数学推理 ❌ 不行 ✅ 突然能做
多步推理 ❌ 不行 ✅ 突然能做

涌现的例子

研究发现：

• 3B参数以下的模型：几乎不会做三位数加法

• 10B参数：突然能做三位数加法了

• 100B参数：能做更复杂的数学推理

这种"突然出现"的能力，就是涌现现象——量变到质变。

6Scaling Law的局限

Scaling Law不是万能的：

  • 只适用于训练损失：预测的是训练集上的效果，实际任务效果可能有差异
  • 不考虑架构改进：比如Transformer比RNN好，这不是Scaling Law能预测的
  • 计算成本巨大：按Scaling Law继续扩大，成本可能无法承受
  • 数据瓶颈：高质量数据可能不够用了

我的判断：Scaling Law告诉我们"做大有用"，但没有告诉我们"做大的上限在哪"。2023年之后，很多研究者开始探索：能不能用更少的参数达到同样的效果？这就是"高效训练"、"模型压缩"等方向的研究动机。

7总结

Scaling Law的核心要点：

1. 模型效果与参数量、数据量、计算量呈幂律关系

2. 效果提升是可预测的，不是随机变好

3. 三者要平衡，不能只增加一个

4. 某些能力会在达到某个规模后"涌现"

5. 但Scaling Law有局限，不能无限扩大

理解了Scaling Law，你就理解了大模型发展的底层逻辑——为什么大家都在"卷参数"、"卷数据"、"卷算力"。因为Scaling Law告诉他们：这样做，效果一定会提升。
