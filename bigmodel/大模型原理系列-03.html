大模型原理系列 03

系列三 位置编码 —— 让模型知道"谁在前面"

我的观点：位置编码是Transformer里最被低估的组件。很多人觉得它就是"加个位置信息"，没什么了不起。但真相是：没有位置编码，GPT-4再大也看不懂任何一句话。

先做个小测试

下面两句话有什么区别？

"我爱你"
"你爱我"

你会说："废话！意思完全相反！"

但如果让一个没有位置编码的AI模型来看，它的答案是——

一模一样。因为Self-Attention只看"有哪些字"，不看"字的顺序"。三个字完全一样，所以AI觉得两句话是一个意思。

0上期回顾：Self-Attention解决了什么问题

前两期我们讲了Transformer的整体架构，以及Self-Attention机制——让每个词都能"看到"其他所有词，从而理解它们之间的关系。

但还有一个问题没解决：这些词在句子里位置不同，意思就不一样——AI怎么知道谁在前面谁在后面？

1一个致命的问题

上一篇讲了Self-Attention：所有字同时参与计算，互相"查户口"。

但并行计算带来一个致命缺陷：模型不知道字的顺序。

"我爱你"和"你爱我"——同样的三个字，在Self-Attention看来完全一样！因为每个字都和其他字做了点积，顺序根本不存在。

这对NLP是灾难级的。因为语言的核心就是"顺序"。

冷知识

中文里有很多"顺序决定一切"的例子：上海自来水来自海上——正着读反着读都是同一句话，但意思完全不同。如果没有位置编码，AI连这种文字游戏都玩不明白。

2解决方案：位置编码

2017年的《Attention Is All You Need》论文给出的方案是：在Self-Attention之前，给每个词的位置信息编码到它的向量里。

核心思路很简单：

如果一个词的embedding向量是x，位置信息是p，那么输入到Self-Attention的向量就是：

输入向量 = x + p

这里的p就是位置编码（Positional Encoding），每个位置都有自己独特的编码向量。

老师：位置编码是什么？

小明：就是给每个字贴个"座位号"。

老师：那为什么不用1、2、3这样的座位号？

小明：嗯……

3为什么不能用简单的序号？

很多人第一反应：给第一个字编号1，第二个字编号2，第三个字编号3……不就行了吗？

不行。原因有两个：

第一：序号无法比较。位置1和位置3的距离是2，位置2和位置4的距离也是2。但机器看到的只是数字"1"和"3"、"2"和"4"，它们无法从数字本身推断出"距离相等"这个关系。

第二：序号无法泛化。如果训练时最长句子是100个字，那序号就是1-100。推理时来了一个150个字的句子，模型根本没学过101-150怎么处理。

所以位置编码必须满足三个要求：

  • 能让模型感知绝对位置（我是第几个）
  • 能让模型感知相对位置（我和别人差多远）
  • 能泛化到没见过的长度

生活中的例子

想象你在电影院找座位。如果座位号只是1、2、3……你能找到第8排和第10排中间隔了几排。但如果座位号是随机分配的A、B、C、F……你就无法判断谁离谁更近。位置编码就是让每个位置有一个"智能编号"，既能找自己，又能算距离。

4正弦位置编码：最优雅的设计

Transformer论文用的是正弦和余弦函数，生成位置编码。

公式是这样的：

正弦函数（sin）

一种周期性波动的数学函数，取值范围是[-1, 1]。sin(0)=0, sin(π/2)=1, sin(π)=0。

类比：就像荡秋千，从最低点荡到最高点再荡回来，这个往复运动就是正弦波。

余弦函数（cos）

和正弦函数类似，也是周期性波动，取值范围[-1, 1]。区别是cos(0)=1，起点不同。

类比：两个人一起荡秋千，一个人先出发（sin），另一个人晚四分之一拍出发（cos）。节奏一样，但起点不同。

公式如下：

PE(pos, 2i) = sin(pos / 10000^(2i/d)) PE(pos, 2i+1) = cos(pos / 10000^(2i/d))

看起来复杂，但其实很好理解。

拆解公式

pos：词在句子中的位置，比如0、1、2、3……

i：维度的索引，比如第0维、第1维、第2维……

d：向量的总维度，比如512

10000^(2i/d)：这是一个"缩放因子"，不同维度用不同的缩放——前面的维度变化快（高频），后面的维度变化慢（低频）。

类比：位置编码就像"GPS坐标"。经度和纬度组合起来，能精确标识地球上的任何一个位置。正弦和余弦函数就像经度和纬度——不同频率的正弦波组合起来，能唯一标识任何一个位置。而且GPS坐标有个特点：相邻位置的坐标值相差不大，远距离位置的坐标相差很大。位置编码也一样——相邻位置的编码向量相近，远距离位置的编码向量差异大。

为什么用sin和cos两个函数？

因为sin和cos之间有一个天然关系：

sin(θ + φ) = sin(θ)cos(φ) + cos(θ)sin(φ)

这个性质意味着：位置pos+k的编码，可以通过pos的编码的线性变换得到。换句话说，模型可以很容易地学会"两个位置之间差多少"。

5位置编码长什么样？

假设我们有一个4维向量（为了简化说明），位置0的位置编码是：

PE(0) = [sin(0), cos(0), sin(0), cos(0)] = [0, 1, 0, 1]

位置1的编码是：

PE(1) = [sin(1/10000^0), cos(1/10000^0), sin(1/10000^(2/4)), cos(1/10000^(2/4))] ≈ [0.84, 0.54, 0.01, 1.00]
图1：位置编码的波形图——不同位置对应不同的正弦波组合

把位置编码加到词向量上，就是最终输入Self-Attention的向量。

图2：位置编码如何加到词向量上——x + p = 最终输入

老师：你看位置0的编码是[0,1,0,1]，位置1的编码是[0.84,0.54,0.01,1.00]。它们不一样，但也不是完全无关。

小明：就像我和我哥？长得像，但不是同一个人。

老师：这个比喻……很对。

6用Python代码验证

光看公式不够直观，我们用代码生成位置编码，看看实际效果：

import numpy as np def get_positional_encoding(max_len, d_model): pe = np.zeros((max_len, d_model)) position = np.arange(0, max_len)[:, np.newaxis] div_term = np.exp(np.arange(0, d_model, 2) * -(np.log(10000.0) / d_model)) pe[:, 0::2] = np.sin(position * div_term) pe[:, 1::2] = np.cos(position * div_term) return pe pe = get_positional_encoding(10, 512) print("位置0的编码（前8维）：") print(pe[0, :8]) print("\n位置0和位置1的距离：") print(np.linalg.norm(pe[0] - pe[1]))

输出：

位置0的编码（前8维）： [0. 1. 0. 1. 0. 1. 0. 1.] 位置0和位置1的距离： 14.14

7为什么这个设计如此巧妙？

正弦位置编码有几个关键优势：

特性 说明 为什么重要
唯一性 每个位置都有独特的编码 模型能区分"我爱你"和"你爱我"
相对位置可计算 PE(pos+k)可由PE(pos)线性变换得到 模型能学会"距离"的概念
泛化性 正弦函数是连续的，可以无限延伸 处理比训练时更长的句子也没问题
平滑性 相邻位置的编码向量相似 符合语言的自然规律——近的词关系更近

我的判断：很多人觉得位置编码只是"一个技术细节"，不值得关注。但我的观点恰恰相反——位置编码是Transformer架构中最优雅的设计之一。它用一个简单的数学函数，解决了并行计算的最大痛点。没有它，Self-Attention再强大也无法处理有序文本。

8其他位置编码方案

除了正弦位置编码，后来还有很多替代方案：

相对位置编码（Relative Positional Encoding）：直接编码两个词之间的距离，而不是绝对位置。这对某些任务（如机器翻译）效果更好。

旋转位置编码（RoPE）：通过旋转操作编码位置信息，被LLaMA、GPT-J等开源大模型广泛采用。

ALiBi（Attention with Linear Biases）：不用位置编码向量，而是在注意力分数上直接加上位置偏置。这个方案在长文本场景下表现优异。

不同的位置编码方案各有优劣，但正弦位置编码仍然是理解位置编码原理的最佳起点。

彩蛋：RoPE为什么火？

旋转位置编码（RoPE）的核心思想是：把位置信息编码成"旋转角度"。位置0是0度，位置1是旋转30度，位置2是旋转60度……旋转操作有个天然的数学性质：旋转角度相加 = 相对位置可计算。这比原始的正弦编码更直观，所以在开源大模型里特别受欢迎。下次如果你用LLaMA，记得它里面的位置编码就是"转圈圈"。

9总结

位置编码的核心思想：在Self-Attention之前，把每个词的位置信息编码成向量，加到词的embedding上。这样模型既知道"这个词是什么"，也知道"这个词在第几个位置"。
