大模型原理系列 04

系列四 多头注意力 —— 让模型从多个角度理解

我的观点：多头注意力是Transformer的灵魂。位置编码让模型知道"谁在前面"，Self-Attention让模型知道"谁和谁有关"，而多头注意力让模型知道——"同一个问题，其实有多个不同的理解方式"。

先问大家一个问题

"苹果"是什么意思？

🍎 水果？📱 手机？💻 电脑？

你肯定能答对，因为你会看上下文。

但如果AI只有一个"脑子"来理解，它可能会——

蒙圈了。因为它只有一个角度理解"苹果"，分不清到底是水果还是公司。

0上期回顾：一个关键问题

上期我们讲了位置编码：通过把位置信息加到词向量上，让AI知道"谁在前面"。

但还有一个问题没解决：AI只有一个角度看问题。

回顾一下Self-Attention的公式：

Attention(Q, K, V) = softmax(QKT / √d) · V

这里的Q、K、V都是通过同一个输入变换而来的。这意味着：一个句子只能从一种"视角"去分析。

生活中的例子

就像你看一幅名画，只用一只眼睛看——看到的是扁平的。但如果你用两只眼睛看，大脑会把两个视角合在一起，变成立体画面。多头注意力就是给AI装上"多只眼睛"。

1解决方案：多头注意力

Multi-Head Attention（多头注意力）的思路很简单：

不要只有一组Q、K、V，而是多组同时算。

核心公式：

MultiHead(Q, K, V) = Concat(head1, ..., headh) · WO 其中 headi = Attention(QWiQ, KWiK, VWiV)

翻译成人话就是：

  • 把Q、K、V分别投影到h个不同的空间（h是"头"的数量）
  • 每个头独立计算一次Attention
  • 把h个结果拼接起来，再做一个线性变换

老师：多头注意力是什么意思？

小明：就是让AI有"多只眼睛"看问题？

老师：很好理解，但不够准确。多头注意力不是"多只眼睛"，而是"多个脑子"。每个头有自己独立的Q、K、V变换，关注不同的信息。

小明：所以每个头可以学到不同的"关注点"？

老师：没错。这就是它的强大之处。

2每个头到底在学什么？

不同的头确实会关注不同类型的信息。研究发现：

头的类型 关注什么 举例
句法头 语法结构 主语在哪里、动词在哪里
语义头 词的意义 "苹果"是水果还是公司
位置头 位置关系 谁在谁的前面/后面
指代头 指代关系 "他"指的是谁

图1：不同注意力头关注不同的信息——有的看语法，有的看指代，有的看语义

3具体例子：一句话的8种理解

比如这句话：

"小明在公园遇到了小红，她正在喂鸽子"

8个"头"会同时分析：

  • 头1：谁和谁在互动？（小明↔小红）
  • 头2："她"指的是谁？（是小红）
  • 头3：在哪里发生的？（公园）
  • 头4：在做什么？（喂鸽子）
  • 头5：动作的承受者是谁？（鸽子）
  • 头6：词和词之间的依赖关系
  • 头7：谁在什么地点做什么
  • 头8：整句话在讲什么故事

最后，8个头的分析结果合在一起，AI就完全理解了这句话。

4为什么多头比单头更好？

想象你要了解一个人：

生活中的例子

如果只问一个人："这人怎么样？"你只能得到一个角度的评价。但如果同时问他的妈妈、老师、朋友、同事——

• 妈妈说："很孝顺"

• 老师说："很聪明"

• 朋友说："很幽默"

• 同事说："很勤奋"

合起来，你才全面了解这个人。多头注意力就是这个道理。

三个关键优势：

优势 说明 举例
更准确 一个头可能看漏重点，多个头互相补充 "苹果"不再混淆
更全面 不同头关注不同类型的信息 语法、语义、指代都能学到
更深入 组合起来能理解复杂关系 长难句不再话下

5用代码验证

PyTorch已经内置了Multi-Head Attention，一行代码搞定：

import torch import torch.nn as nn # d_model: 词向量维度, nhead: 头的数量, dim_feedforward: FFN维度 mha = nn.MultiheadAttention(embed_dim=512, num_heads=8) # 输入: (序列长度, batch, 维度) query = key = value = torch.randn(10, 1, 512) # 输出: (序列长度, batch, 维度) output, attn_weights = mha(query, key, value) print(output.shape) # torch.Size([10, 1, 512])

6不同模型的"头"数量

头数不是越多越好，要权衡效果和效率：

模型 头数 向量维度 每个头的维度
原始Transformer 8 512 64
BERT-Base 12 768 64
BERT-Large 16 1024 64
GPT-3 96 12288 128

我的判断：BERT用12个头，GPT-3用96个头。这不是随便定的——头数越多，每个头能关注的信息越细致，但计算量也越大。BERT是encoder模型，需要理解完整的句子结构；而GPT是decoder模型，需要生成连贯的文本。任务不同，最优的头数也不同。

7总结

多头注意力的核心思想：不要只有一组Q、K、V，而是多组同时计算。每个头有自己独立的投影矩阵，关注不同类型的信息。最后把所有头的输出拼接起来，让模型能从多个角度理解文本。

一句话记住：多头注意力就是让AI有"多个脑子同时分析"，每个脑子抓一个重点，大家一起把句子读懂。
