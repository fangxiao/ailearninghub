# 宝玉开源中文自媒体全流程技能 (Baoyu Media Skills)

## 核心工作流三步法 (Three-Stage Pipeline)
1. **风格去 AI 味与人话重写 (Humanizing & Feynman Style)**：
   - 拒绝宏大叙事与空泛修辞（坚决删除“炸裂、神级、颠覆认知、令人望而生畏”等感叹句）；
   - 用生活化比喻拉近距离（如用“去餐馆吃面”比喻“传统自建服务器”）；
   - 短句子、多口语化转折（“其实”、“你想想看”、“我们来看两笔账”）。
2. **多平台矩阵分发适配 (Multi-Platform Transformation)**：
   - **微信公众号**：1800~2500 字深度长文，配备 100% Inline CSS 结构化排版与章节序号；
   - **小红书 (Xiaohongshu)**：5~7 张图文卡片大纲，突出痛点、避坑要点与可复制清单；
   - **X / 微博**：300 字核心金句 + 3 点核心提炼 Thread。
3. **视觉与信息图设计 (Infographic Prompts)**：
   - 提取文章中的因果逻辑与流程走向，生成标准 Mermaid 流程图或 SVG 可视化结构；
   - 采用统一的配色规范（主色 Teal 墨绿 / 深蓝，辅助色 Amber 暖黄）。
