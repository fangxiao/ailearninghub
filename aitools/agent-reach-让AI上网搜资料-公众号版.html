01 Agent Reach 到底是什么？

Agent Reach 是一个开源工具，专门给 AI Agent 装"上网"能力。它的核心思路是把"读网页、读视频、读社交平台"这件事标准化。你不用再为每个平台单独写爬虫、配代理、存 Cookie，Agent Reach 已经封装好 14 个平台的访问接口，AI 直接调用即可。

说得再直白一点：

🌐 不是搜索引擎：它不索引全网，而是帮 AI 实时访问具体平台的内容

🔌 不是 MCP 服务器：它通过 MCP 协议接入，但本身是一个独立的工具集

🎯 不是浏览器自动化：不依赖 Playwright/Selenium 那套，直接走平台接口，速度快、稳定

📦 是一个"网络访问增强层"：装上之后，AI 就有了读小红书、B 站、Twitter 等平台内容的能力

以前想让 AI 读个 B 站视频详情，得自己写脚本抓接口、处理反爬、清洗数据，再喂给 AI。现在装上 Agent Reach，直接说"读一下这个 B 站视频的详情"，AI 自己就会调用对应工具，把标题、简介、UP 主、评论数都拿回来。

02 一句话安装，更新也是一句话

Agent Reach 的安装方式很特别，不是敲命令，而是用自然语言让 AI 帮你装。你只需要在对话里说一句"帮我安装 Agent Reach"，AI 会自己拉取安装文档、执行安装流程。

1 安装：一句话触发

在 AI 对话框里直接说：

帮我安装 Agent Reach # AI 会自动拉取下面的安装文档并执行

安装文档地址（AI 会自动读取）：

https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/install.md

2 更新：同样一句话

已安装的用户想升级到最新版，直接说：

帮我更新 Agent Reach # AI 会读取更新文档并执行升级

更新文档地址：

https://raw.githubusercontent.com/Panniantong/agent-reach/main/docs/update.md

3 诊断：检查是否装好

装完跑一遍诊断命令，检查所有平台连通性：

agent-reach doctor # 检查所有平台连通性

⚠️ OpenClaw 用户注意：需要先开启 exec 权限，否则 Agent Reach 无法执行命令：

openclaw config set tools.profile "coding" # OpenClaw 用户先开启 exec 权限

🔐 安全提示：agent-reach install --system 是系统级安装，会写入全局配置，仅在明确授权后由 AI 执行。

04 实战演示：3 个典型场景

光说能力不够直观，下面跑 3 个真实场景，看看装上 Agent Reach 之后 AI 是怎么"上网"的。

1 场景一：读 B 站视频详情

你的需求：拿到一个 B 站视频链接，让 AI 总结视频讲了什么。

对 AI 说：

读一下这个 B 站视频的详情，总结要点：https://www.bilibili.com/video/BV1xxxxxx

AI 自动做的事：

  • 调用 Agent Reach 的 B 站工具，拉取视频标题、简介、标签、UP 主信息
  • 提取分 P 列表和评论数，判断视频热度和讨论方向
  • 把原始数据整理成"一句话总结 + 3 个要点 + 适合人群"的结构

耗时：约 10 秒，对比之前自己复制粘贴简介再喂给 AI，省了好几步。

2 场景二：搜小红书最新防晒测评

你的需求：想知道最近小红书上热门的防晒霜测评，挑出 3 款口碑好的。

对 AI 说：

帮我搜一下小红书上"防晒霜 测评"这个关键词，挑出最近 3 篇互动量最高的笔记，总结推荐

AI 自动做的事：

  • 通过预先配置的小红书 Cookie 访问搜索接口
  • 按互动数（点赞 + 收藏 + 评论）排序，取前 3 篇笔记正文
  • 提取每篇笔记推荐的产品、肤质适用场景、踩雷点
  • 交叉对比，给出"油皮推荐 / 干皮推荐 / 敏感肌推荐"三档结论

前提：需要先在小红书平台登录，把 Cookie 配到本地，这是一次性操作，配完之后所有对话都能用。

3 场景三：读 Twitter 某博主最近发言

你的需求：想了解某个 AI 领域博主最近一周发了什么，有没有新观点。

对 AI 说：

读一下 @某个博主 的 Twitter 时间线，挑出最近一周关于 AI Agent 的发言，整理成中文摘要

AI 自动做的事：

  • 用配置好的 Twitter Cookie 拉取博主时间线
  • 按时间过滤近 7 天内容，关键词匹配"AI / Agent / LLM"
  • 翻译英文推文，提取核心观点和引用的链接
  • 输出"博主本周 3 个核心观点 + 2 个值得关注的趋势"

对比传统方式：不用自己一条条刷 Twitter、复制粘贴、再让 AI 总结，一句话搞定。

05 安全与隐私：Cookie 不外泄

涉及到 Cookie、登录态这种敏感信息，大家最关心的就是：我的账号会不会被盗？数据会不会被上传？Agent Reach 在这件事上做了三层防护。

🔒 第一层：Cookie 只存本地

所有平台的 Cookie 都保存在你本机，不会上传到任何服务器。AI 调用工具时，是在你的本地环境里读取 Cookie 发起请求，整个过程不经过第三方。

📂 第二层：代码完全开源

Agent Reach 是开源项目，所有代码在 GitHub 公开。你可以审查每一行逻辑，确认它到底读了什么、发了什么请求、有没有偷偷上报数据。开源是隐私保护最硬核的底气。

🛡️ 第三层：install 默认安全模式

agent-reach install 默认只装公开平台访问能力，不会自动配置任何需要登录的平台。需要登录的平台（小红书、Twitter 等）必须你手动配 Cookie 才会启用，不会偷偷开权限。

💡 实操建议：建议给需要登录的平台单独配一个低权限账号的 Cookie，别用主账号。这样即使 Cookie 意外泄露，影响也有限。

07 3 个常见疑问

Q1：需要翻墙吗？

国内平台（小红书、B 站、知乎、雪球、V2EX、小宇宙）不需要翻墙，直接走本地网络。访问 Twitter、Facebook、Instagram、YouTube、Reddit、LinkedIn 这些海外平台时，需要你本机能正常访问这些站点——能不能直连取决于你的网络环境，Agent Reach 本身不内置代理。

Q2：收费吗？

Agent Reach 是完全开源免费的，代码在 GitHub 公开，不收任何费用。你只需要承担自己使用 AI 助手时产生的 token 费用（如果用的是付费 AI 服务），Agent Reach 本身不收费。

Q3：支持哪些 AI Agent？

Agent Reach 通过 MCP 协议接入，凡是支持 MCP 的 AI Agent 都能用，包括 Claude Code、Cursor、OpenClaw、Codex、OpenCode 等主流编程 Agent，也包括其他支持 MCP 协议的对话型助手。安装方式都是一句话触发，AI 自己读文档搞定。

✨ 写在最后

AI 很多时候显得"不够聪明"，毛病往往不在模型身上，而在于它看不到最新、真实的世界。训练数据有截止日期，平台内容每天都在变，没有联网能力的 AI 就像个只能翻旧报纸的助手。

Agent Reach 把"上网"做成了一件开源、一句话安装、覆盖 14 个平台的标准能力。装上之后，AI 终于能读到小红书的真实测评、B 站的视频内容、Twitter 的实时讨论，即时感和信息量都和过去完全不一样了。
