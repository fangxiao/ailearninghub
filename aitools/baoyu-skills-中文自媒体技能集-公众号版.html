宝玉开源的中文自媒体全流程技能集

AI 自媒体工作流推荐 | Claude Code 中文 Skill 合集

做自媒体的人，大概率被这套流程折磨过：

❌ 写完一篇文章，还要手动出封面、做信息图、剪小红书图，整套流程耗半天

❌ AI 出的图风格飘忽，第一张和第十张像两个设计师做的，根本没法成系列

❌ 公众号、微博、X、小红书，每个平台格式不一样，复制粘贴调样式调到崩溃

❌ 想批量做图文，市面工具要么贵、要么不支持中文、要么得自己写脚本

这些问题的核心是：内容生产链路是断的——写作、出图、排版、分发各干各的，没人把它们串成一条流水线。宝玉（@dotey）开源的 baoyu-skills，就是想把这条流水线在 Claude Code 里跑通。

一句话总结：15 个 Skill 覆盖内容生成、AI 出图、多平台分发，支持 Claude Code、Cursor、Codex，GitHub 6000+ Star。

01 baoyu-skills 是什么？

baoyu-skills 是宝玉（Jim Liu，X 账号 @dotey）开源的 Claude Code 技能集。宝玉在国内 AI 圈靠翻译和技术解读出名，这个仓库则是他把自己日常的自媒体工作流打包成了 Skill。截至撰稿，GitHub 累计 6000+ Star、700+ Fork，从 2026 年 1 月立项到现在的 v2.2.1，迭代了 690+ 次。

它是 15 个 Skill 的合集，按职能分成三个 Plugin：内容生成（Content Skills）、AI 出图后端（AI Generation Skills）、内容处理工具（Utility Skills）。装上之后，Claude Code 就多了出小红书图、做封面、转 Markdown、发公众号这些能力。

跟之前介绍的 Khazix-Skills（写作风格迁移）和 Humanizer（去 AI 味）不同，baoyu-skills 不改文字，只把文字变成图、PPT、漫画、多平台稿件，覆盖的是内容生产的下游链路。三者完全可以组合使用：Khazix 调风格 → Humanizer 去味 → baoyu-skills 出图分发。

02 三大技能包：15 个 Skill 全清单

baoyu-skills 的 15 个 Skill 按 Plugin 分组，每个 Plugin 可以单独装：

Plugin 用途 包含 Skill 数
content-skills 内容生成与多平台发布 9 个
ai-generation-skills AI 绘图后端 2 个
utility-skills 内容处理工具 5 个

内容技能（Content Skills）是整个合集的核心，9 个 Skill 覆盖了从信息图到多平台发布的完整链路：

Skill 作用
baoyu-xhs-images 小红书信息图系列生成器，9 风格 × 6 布局
baoyu-infographic 专业信息图，20 种布局 × 17 种风格
baoyu-cover-image 文章封面图生成
baoyu-slide-deck Markdown 转 PPT
baoyu-comic 漫画生成
baoyu-article-illustrator 为文章自动配插图
baoyu-post-to-x 发布到 X / Twitter
baoyu-post-to-wechat 发布到微信公众号
baoyu-post-to-weibo 发布到微博

其中 baoyu-xhs-images 是核心 Skill。它不是简单生成一张图，而是把一篇文章拆成 1-10 张卡通风格信息图，支持风格 × 布局二维系统：

维度 选项 用途
风格（9 种） cute / fresh / warm / bold / minimal / retro / pop / notion / chalkboard 视觉美学
布局（6 种） sparse / balanced / dense / list / comparison / flow 信息密度

另一个细节是风格一致性机制：生成第 2 张及之后的图时，会把第 1 张作为 --ref 参考传给底层模型，保证整套图视觉统一，这条细节是手画或单图 AI 工具很难做到的。

AI 生成技能（AI Generation Skills）是出图后端，包含 image-gen 和 danger-gemini-web 两个 Skill。image-gen 默认调用 Nano Banana Pro 模型（通过 Replicate 平台），content-skills 里所有图像生成 Skill 底层都走它。这层抽象的好处是：换模型只改一处，所有上层 Skill 自动跟新。

工具技能（Utility Skills）负责内容处理：url-to-markdown 把网页转 Markdown、compress-image 压图、format-markdown 排版、translate 翻译、danger-x-to-markdown 抓 X 推文。这些是给前面两个 Plugin 当"扳手"用的小工具。

03 安装：三种方式任选

baoyu-skills 的安装命令都在官方 README 验证过，前置要求只有一条：已安装 Node.js，能跑 npx bun。

方式一：npx 一键安装（推荐）

npx skills add jimliu/baoyu-skills

方式二：在 Claude Code 中注册插件市场

/plugin marketplace add jimliu/baoyu-skills

注册后，在 Claude Code 输入 /plugin，选 Browse and install plugins → baoyu-skills → 按需安装三个 Plugin。

方式三：直接装指定 Plugin

/plugin install content-skills@baoyu-skills

/plugin install ai-generation-skills@baoyu-skills

/plugin install utility-skills@baoyu-skills

方式四：直接告诉 Agent

请帮我安装 github.com/JimLiu/baoyu-skills 中的 Skills

更新方式：在 Claude Code 输入 /plugin → 切到 Marketplaces 标签 → 选 baoyu-skills → Update marketplace。也可以勾 Enable auto-update，每次启动自动拉新版。

04 实战：一篇文章跑通全流程

假设你写完了一篇 Markdown 文章 posts/ai-future/article.md，下面是完整的发布流程。

① 出小红书系列图

# 自动选风格和布局

/baoyu-xhs-images posts/ai-future/article.md

# 指定 Notion 风格 + 密集布局

/baoyu-xhs-images posts/ai-future/article.md --style notion --layout dense

# 直接输入内容

/baoyu-xhs-images 今日星座运势

② 出专业信息图

# 鱼骨图 + 赛博朋克霓虹风

/baoyu-infographic content.md --layout fishbone --style cyberpunk-neon

③ 转 PPT

/baoyu-slide-deck article.md --style corporate --slides 15

④ 多平台分发

# 发布到公众号

/baoyu-post-to-wechat article.md

# 发微博

/baoyu-post-to-weibo article.md

# 发 X 长推

/baoyu-post-to-x "Thread about AI skills"

整套流程跑下来，一篇 Markdown 文章能变成小红书 9 图、专业信息图、15 页 PPT、公众号+微博+X 三端稿件。原本两个人一天的工作量，压缩到一杯咖啡的时间。

05 避坑指南：4 个常见问题

⚠️ 坑 1：npx bun 跑不起来
image-gen 底层依赖 Bun 运行时。如果报错，单独跑一次 npx bun 触发安装，或者直接 npm i -g bun 装全局。

⚠️ 坑 2：出图调用失败、报 401
image-gen 默认走 Replicate 调 Nano Banana Pro。需要在环境变量配置 REPLICATE_API_TOKEN。没有 token 也可以改用本地 ComfyUI 后端，baoyu-skills 支持多后端切换。

⚠️ 坑 3：发公众号提示无权限
baoyu-post-to-wechat 需要公众号的 AppID 和 AppSecret，提前在环境变量配好。临时素材上传受公众号接口限频，密集发布会触发 45009 错误，建议每天单账号不超过 10 篇。

⚠️ 坑 4：风格选项填错没报错
xhs-images 风格名是 cute/fresh/warm/bold/minimal/retro/pop/notion/chalkboard 这 9 个，写错会静默回退到默认 cute。出图前先用 --help 确认拼写。

06 横向对比：和同类工具差在哪

工具 定位 Skill 数 中文适配
baoyu-skills 自媒体全流程 15 原生中文

简单说：anthropics/skills 处理的是 PDF/Word/Excel 这类文档（参见《anthropics/skills 官方技能库》）；Khazix-Skills 调的是写作风格（参见《Khazix-Skills 写作风格迁移》）；Humanizer 去的是 AI 味（参见《Humanizer Skill 介绍》）；而 baoyu-skills 干的是出图 + 分发——四者各管一段，能完整拼出一条"写作 → 风格 → 去味 → 出图 → 发布"的中文自媒体流水线。
